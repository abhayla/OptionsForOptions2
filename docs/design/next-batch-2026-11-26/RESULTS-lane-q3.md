## How it is built (no product code touched)
- Worker = `python -m ofo_app.background`, OFO_SCENARIO=PATH-nn, APP_ENV=test, own PostgreSQL clone per case. The test writes the frame index (`scenario_mode.write_frame`); the worker moves its clock and prices to that frame.
- New test paths: PATH-90 (flat then loss), 91 (cross and dip back), 92 (profit by an IV drop), 93 (flat, time exit), 94 (10 percent loss held), 95 (stale prices from 11:42), 96 (entered 11:40 already at a loss). Generated by tests/adjust_scenarios_gen.py; one optional new spec key `entry_clock` (existing specs unchanged: all 248 frames regenerate byte-identical).
- The worker's clock is the scenario's and stands still inside a frame: a row present after a frame's wait was raised at that frame's check; a row that comes only at the next frame came at the candle close.
