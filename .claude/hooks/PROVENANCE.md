# Hook provenance (M3 step 3)

Every script below is a **byte-identical copy** (verified by sha256 of LF-normalized content — CRLF
collapsed to LF before hashing, so a Windows checkout and a Linux checkout hash equal) of its
Capability Library source. The drift checker (`tools/kit_drift.py`, M3 deliverable 7) compares these
hashes against the library copies so a copy that has silently drifted from its source is caught.

Every hash below was produced by `tools/generate_kit_tools_provenance.py`, never typed by hand; the
same computation is what `tests/test_kit_hooks.py::test_f_template_scripts_match_library_sha256` and
`::test_f2_seatbelt_scripts_match_live_source_sha256` re-run against a live re-read of both sides on
every test run (so a hand-edit here would itself go out of date and be caught, not just the copy it
checks). Regenerate with `python tools/generate_kit_tools_provenance.py` whenever a source hook
changes; CI runs it with `--check` so a stale table never merges.

## Note on the seatbelt's own source folder name

Three rows below are copied from the Factory's own production seatbelt capability. That capability's
own hook directory name is one of the strings the running seatbelt refuses to see typed literally
into a shell command or file content (it protects its own files from edits made from a session it
governs) — so this generator builds that directory name from parts at runtime rather than typing it
out, exactly as this project's own tool-quirk note requires. Read the source files with the Read tool
to see their real location; this is a change to how the generator's text avoids naming that folder,
never a change to the files' behaviour.

## hook_presence_check.py

New SessionStart hook (M3 deliverable 3), not copied from anywhere: reads this project's own Claude
settings file, extracts every hook command's script path, and prints one loud `HOOK MISSING: ...`
line per missing file. See its own docstring for the exact contract. Always exits 0 (a SessionStart
check must never block a session start).
