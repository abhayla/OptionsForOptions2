# Rule provenance

The rules below live in `.claude/rules/kit/` (kit-owned, OD-22); a project's own rules go in `.claude/rules/project/`.

Where each kit rule came from and what changed. The Factory library keeps the exact origins; this file names
sources generically so it can ship into any project. Common to every row: generalized for any project (no personal
or project names, absolute paths, hosts, local clock times or project-specific numbers); legacy-system references
(multi-project task queues, shared cross-project fact and secret files, a shared notification gateway, laptop-only
hook names) removed; each incident reduced to one generic "why" line; paths pointed at this template (`spec/`,
`spec/decisions/`, `work/`, `evidence/`, `releases/`, `knowledge/findings/`, `views/`). Kit version 1.0.0 (M3 step 2).
