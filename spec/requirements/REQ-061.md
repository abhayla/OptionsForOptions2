# REQ-061: Existing positions on connect

When Zerodha connects, open positions are fetched and the user decides how to group them.

Decisions: ADR-018. Sources: M §50; H1 §23; H2 §23.

**Owner decision (2026-10-15, Q270, ADR-084):** AC-1's possible structures are suggested one group per underlying and
expiry, confirmed by the user; an adopted leg's entry price is Zerodha's average price, editable before confirming.

**Finding (2026-10-19):** F-52 - AC-2 (add a held position to an existing strategy) is not waiting on OQ-7: ADR-096
answered it on 2026-10-16 ("Build it now", the order-free adopt path), but the generated build order and `work/W-083.md`
still said "blocked"; the work item is corrected.

**Open:** Detailed grouping algorithm: open (§95). See `spec/open-questions.md`.
