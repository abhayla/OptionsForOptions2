# REQ-128: Data retention schedule

Why: REQ-013 AC-3 and REQ-074 name two retention rules, and the rest of the stored data (sessions, drafts, timelines,
audit rows, notification logs, error-tracker events) has no stated period. Data kept without a period is a DPDP
exposure and a cost; a period guessed without the legal review is worse, so AC-2 writes "unset" until Q211 fills it.

Example: an expired sign-in session row from 1 October is deleted by the 2 October run (AC-3); a closed strategy's
timeline is kept for the period the schedule names, while an open strategy's timeline is never touched (AC-4).

Decisions: ADR-022. Findings: F-27. Open: Q211.
