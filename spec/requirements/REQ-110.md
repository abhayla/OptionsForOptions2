# REQ-110: Daily "does Zerodha agree" report

Why: users trust a strategy app more when it tells them, every day, that its record matches their broker - and when it
does not (register MR-123; Tradetron's daily statement check). Zerodha's day books are empty the next day, so the check
must run the same day.

Example: on 21 Oct at 16:00 the report reads "Strategy 9 - Matches Zerodha. Strategy 11 - Zerodha shows a SELL 65 NIFTY
24700 CE at 14:22 that this app did not place; reconciliation required."

Decisions: ADR-018 (Zerodha wins), ADR-053.
