# REQ-117: Broker capability flags

Why: brokers differ in what they offer (Sensibull keys features on flags such as "MIS supported"). Adding the flags now,
with one broker, costs little; retrofitting after a second broker touches every route (register MR-080).

Example: the stop-at-Zerodha option asks `broker_held_triggers`; for Zerodha it is off until the static-IP proof passes, so
the option shows "Not available yet" instead of failing at Kite.

Technical decision (orchestrator, master register 2026-10-21, TECH row MR-080).

Decisions: ADR-017 ("a broker-specific capability matrix when more brokers come"), ADR-029.
