# REQ-020: Admin: qualifying Client ID management

Admins manage the qualifying Client ID list with validation and audit.

Decisions: ADR-024. Sources: M §66; H2 §7; Q70.

## Owner decision (2026-09-29, Q234): Zerodha Client ID format
- A Zerodha Client ID is **6 characters: 2–3 letters followed by digits** (owner, as the Zerodha AP: "2-3 letter at
  the beginning + 3-5 digits. Total length 6"). With a total of 6 this admits exactly two shapes: 2 letters + 4 digits
  (e.g. AB1234) or 3 letters + 3 digits (e.g. ABC123). Letters are case-insensitive on input and stored upper-case.
  Replaces the unverified W-010 guess (2–3 letters + 3–6 digits).
