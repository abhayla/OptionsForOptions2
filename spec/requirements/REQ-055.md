# REQ-055: Margin checks

Margin is checked with Zerodha before the order basket is built and again after the user places it.

Decisions: ADR-016, ADR-054. Approved 2026-10-15 by the owner (Stage 4b/4c batch); the earlier "submit" and
"continue/stop" wording assumed the platform sends orders, which ADR-054 replaced with the Kite basket. Sources: M §44; H1 §20; H2 §22.

**Finding (2026-10-19):** F-50 - Kite's basket page shows "Required margin" and "Final margin"; the order sequence
changes the required margin and not the final one. The Execute screen shows Zerodha's figure as the authority and ours
as an estimate (AC-1, AC-3).
