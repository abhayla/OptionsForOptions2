# REQ-075: Coding standards, checked automatically

Why: on 2026-10-16 the Kite host typed in a second module let a client go around the order guard, the IST offset was
found defined in 11 modules, and three JSON reads could turn money into floats with nothing to catch it (ADR-093).
Rules kept only in prose were skipped; checks that run by themselves hold.

Example: a builder types `timedelta(hours=5, minutes=30)` in a new module. The edit hook passes it (not a lint rule),
but the one-home test fails on the pull request and names `ofo/timeutil.py` as the home (AC-1). A docs-only pull
request runs the kit checks and the close-keyword check, and no API or frontend job (AC-7).

Not adopted (ADR-093): docstrings on every function, annotations everywhere, strict mypy from day one, 100% coverage,
asserts banned in tests, formatting rules before one formatting-only PR.

Decisions: ADR-093.
