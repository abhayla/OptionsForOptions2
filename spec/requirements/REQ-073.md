# REQ-073: Orders through Kite's own order page

Why: NSE counts every order sent through a broker API as an algo order (F-17) and wants algo providers' strategies run
on the broker's servers (F-18); Zerodha's offsite execution sends users to "Kite's exchange approved order page where
they place orders" (F-22).

Example: an Iron Condor's exit plan has 4 orders. The user presses Execute Strategy, Kite's page opens with the 4
orders locked, the user places them, and returns; we read Zerodha's order book by our tag and reconcile.

Decisions: ADR-054. Open: Q259 (Zerodha's confirmation; basket size limit and how a rejected leg is reported).
