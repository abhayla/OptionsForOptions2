# REQ-147: Target-day futures prices

Why: option values at a target date depend on the forward price of each expiry on that date. Sensibull lists it on
screen 013 so the user can see what the model assumed. OFO2 shows only today's forward price per expiry (REQ-080
AC-6), so a user cannot see what was assumed for the target day (gap row G-062).
