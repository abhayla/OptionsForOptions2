# REQ-111: Strategy notes

Why: a user wants to write down why they took a trade and what would make them exit, and read it back later, as
Sensibull allows (register MR-125).

Example: on strategy 9 the user writes "Entered for the RBI week; exit if NIFTY closes above 24,600." It shows "21 Oct
10:05, version 1".

Decisions: ADR-152 (Sensibull default).
