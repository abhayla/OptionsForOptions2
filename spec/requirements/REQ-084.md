# REQ-084: What-if controls and the Greeks panel

Why: a beginner's first question about a strategy is "what if NIFTY is at X on day Y?", and "what if volatility
rises?". The owner chose Sensibull's three controls (ADR-151, superseding ADR-120 (1)); the engine computes every
number. MR-021 (IV per strike, IV offset) was re-triaged to WRITE under ADR-151.

Register: MR-020, MR-021, MR-025.

Note for the docs PR: REQ-034 AC-6 ("two modes only") is rewritten there to add these inputs, as ADR-151 says; this
file does not edit REQ-034.

Decisions: ADR-151, ADR-152, ADR-120, ADR-008, ADR-056, ADR-063.
