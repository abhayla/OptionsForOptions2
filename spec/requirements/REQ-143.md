# REQ-143: Add Booked P&L chart toggle

Why: a user who closed part of a tracked strategy wants the chart to show the whole story, not only the legs still open.
Sensibull has this toggle on screen 012. The owner put it out of the current phase (ADR-196 (4)) because it needs
tracking and positions first; this requirement records what it is so it is built to a written rule later. The name
"Add Booked P&L" was also used for typed Manual P/L (REQ-089) until the P6 correction of 2026-10-27; this one is only
the Zerodha-fill figure.
