# REQ-015: Zerodha connection

Zerodha connection is optional until needed, never asks for secrets, and its session lifecycle never affects identity or data.

Decisions: ADR-020. Sources: M §59, §60, §82; H2 §10; C Q176, Q185–Q188; CH1/CH2 continuation prompt; Q79 = A, Q80, Q94 = A.

**Open:** How users connect and what it costs them: Q210. Session lifetime to verify from current Kite docs. See `spec/open-questions.md`.
