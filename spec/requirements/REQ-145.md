# REQ-145: Decay column and IV as percent in the Greeks tab

Why: Sensibull's Greeks tab shows five columns including Decay; ours shows four and prints IV as 0.183667 with four
decimals (gap row G-057). A user comparing the two sees a missing column and an IV that reads as a decimal fraction, not
a percent. The study defines Decay only as a tooltip, so the first step is to measure it, as REQ-142 does for Funds
needed.
