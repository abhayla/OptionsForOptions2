# REQ-087: Option Chain display options

Why: a user scanning the chain wants rupee amounts per lot, which strikes are already in the money, more or fewer
strikes, and at a glance how far each option must move to break even. Sensibull's chain has all of these (study
2026-10-21). The spreadsheet download (register MR-151, held) is REQ-131.

Register: MR-048 (DECIDED; REQ-029 had no AC for intrinsic, time value and breakeven %), MR-050. MR-049 (OI bars, OI
change %) stays covered by REQ-029.

Decisions: ADR-152, ADR-008, ADR-056.
