# REQ-042: Automation: Alert + Prepare Orders

When a condition is met the platform alerts and prepares orders; the user always executes.

Decisions: ADR-009. Sources: M §13; C-file (real Q numbers: spec/traceability/question-register.md); H1 §12.

**Findings (spec/findings.md, 2026-10-07):** F-17 - NSE treats every order sent through a broker API as an algo order,
even one the user reviews and confirms; F-18 - an algo provider's strategies must run on the broker's servers. How
prepared orders reach Zerodha (AC-2) is open for owner decision as Q259.
