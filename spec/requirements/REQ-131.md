# REQ-131: Option chain spreadsheet download, held for redistribution permission

Why: the owner applied the Sensibull default (ADR-152) and held the download for written permission (ADR-156 (4)),
because a downloaded file is exchange data leaving the platform (F-23).

Example: after permission, a user on the NIFTY chain presses "Download" at 10:42:05 and gets the 21 strikes on screen
with LTP, OI and IV and the read time (AC-2).

Decisions: ADR-156, ADR-155, ADR-152. Findings: F-23. Register row: MR-151.
