# REQ-095: In-app help (held)

Why: a user stuck on a screen wants an answer without leaving the app, and wants to know what changed. Sensibull has
support chat, FAQ and What's New (study 2026-10-21). The chat tool costs money every month, so the owner held this
until that cost is cleared (ADR-156 (5)).

Register: MR-157.

Decisions: ADR-156, ADR-152, ADR-003.
