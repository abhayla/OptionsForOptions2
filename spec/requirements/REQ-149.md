# REQ-149: Phone layout of the builder at 390 px wide

Why: traders check a strategy from a phone. Sensibull has a dedicated phone layout (study screenshot 250). Ours squeezes the desktop layout, so on a 390 px screen the top navigation is cut off and Market, Orders and Learn cannot be reached (gap list G-069). REQ-004 sets mobile priorities but names no builder layout.
