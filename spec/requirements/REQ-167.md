acceptance_criteria:
- id: AC-1
  text: >-
    A settings registry (a data file) lists every app-wide setting: key, group, label, unit, type, allowed range,
    default and a one-line "what it changes". The store keeps each change as a new dated row (append-only, like the
    charge rates of ADR-082); the value in force at a time is the newest row not after that time, else the default.
- id: AC-2
  text: >-
    The Settings page shows the settings by group with the value in force, the default, when it took effect and who
    set it, and the history of earlier values. The admin changes a value with an effective time (now by default); a
    value outside the allowed range or of the wrong unit is refused with the reason (e.g. 6.5 typed for a rate whose
    unit is a fraction: "Enter 0.065 for 6.5%"). Reset to default is a new row, never a delete.
- id: AC-3
  text: >-
    Only the admin can change a setting; every change is written to the audit log. Until sign-in exists the admin is the
    single owner; every settings write passes one guard that becomes the admin role check when sign-in lands.
- id: AC-4
  text: >-
    Each wired calculation reads the value in force when it runs (no restart): changing a setting changes the next
    figure, alert or choice for every user and every tracked strategy at its next check; a strategy's saved plan
    (REQ-161) is not changed (ADR-222 (9)). A test proves it for each wired setting.
- id: AC-5
  text: >-
    The groups are: Charges (the ADR-082 rate table, shown from its existing dated table, a new rate set added from the
    page with its source URL); Pricing (risk-free rate; forward quality width, strikes near, minimum strikes); Scenarios
    and payoff (scenario columns, strangle quick picks, what-if span, payoff table steps, SD horizon); Limits (range
    pick-list cap and step, chain strikes each side, leg-picker widths, lot and history caps); Detection (feed stale and
    reconnect windows); Billing (trial and referral days); Speeds (live push interval, REQ-166); Data (maximum delist
    percent, freeze file stale after); Exchange and broker facts (market hours and expiry close, paper settlement window,
    Kite session expiry, freeze units and batch, Zerodha rate and feed limits, quote limit, tick, stamp and SEBI caps,
    contract-list publish time), each with its source in the note; Adjustment defaults (the starting value of every
    REQ-168 preference, ADR-222 (7)).
- id: AC-6
  text: >-
    A guard test fails when a module wired to settings holds a business literal again, and when a registry key has no
    reader.
- id: AC-7
  text: >-
    The Undo window becomes a setting with a default waiting on the owner (F-79, owner question Q-SET-1); until then
    the code's 8 s (one leg) and 10 s (Clear all) are the defaults.
