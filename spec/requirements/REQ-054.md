# REQ-054: Broker adapter

Zerodha is reached through a minimal broker adapter.

Decisions: ADR-016, ADR-050 (AC-3, AC-4 added 2026-10-02). Sources: M §76; C-file (real Q numbers:
spec/traceability/question-register.md); H1 §8.

## Findings this requirement rests on (spec/findings.md)
- F-01 (exchange token shared by all brokers), F-02 (Zerodha's instrument_token is not), F-03 (symbols differ and are not
  unique), F-04 (scales and limits differ per broker), F-08 (plugin-per-broker reference design, licence unchecked),
  F-06 (SEBI static IP and algo ID affect the adapter; open for owner decision, Q258).
