# REQ-086: Share a read-only link to a plan

Why: traders talk about plans with friends and mentors, and a link is how they do it (word of mouth for the product).
Sensibull shares by link (study 2026-10-21). OFO2 already opens a draft from a URL (W-073). The limits come from
existing decisions: live data stays behind login (ADR-027) and nothing is ranked or claimed as performance (ADR-055).

Register: MR-034.

Isolation: the shared-link route is the one named public read of REQ-125 (AC-11) - open to any signed-in user holding
the link (AC-3), never scoped to the sharer; it returns only the frozen copy of
AC-1 with none of the AC-5 account data, and REQ-125's two-user replay suite lists it as the expected exception.

Decisions: ADR-152, ADR-027, ADR-055, ADR-053, ADR-002.
