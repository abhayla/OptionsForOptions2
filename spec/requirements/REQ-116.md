# REQ-116: Notifications through the shared Notifier, outside the order path

Why: the owner runs one notification gateway for all projects (ADR-040); a parallel sender would duplicate secrets and
templates. And an alert channel that fails must never stop the thing it was reporting on (register MR-118).

Example: Wati is down at 14:10 when a stop fires. The trigger record and the in-app alert are stored at once; the
WhatsApp send times out, is retried with the same dedupe key at 14:12 and 14:15, succeeds once, and the alert shows
"WhatsApp: sent 14:15".

Technical decision (orchestrator, master register 2026-10-21, TECH row MR-118).

Decisions: ADR-028, ADR-040.
