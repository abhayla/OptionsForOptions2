# REQ-138: Builder settings saved per user

Why: Sensibull keeps these builder choices as account settings (study 2026-10-21, screens 025, 243-246) so a user
sets them once. ADR-152 makes that the default. The per-user settings store added for the option chain (migration 0022,
W-124) is the place to keep them.
