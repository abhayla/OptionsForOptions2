# REQ-146: P&L Table target columns and readable contract dates

Why: Sensibull's P&L Table shows what each leg is worth at the user's target (screen 014); ours shows only today's
numbers, and prints the contract as "65 2026-11-03 22,300 PE" (gap row G-056). The compact table is kept as the default
(ADR-194); the target columns appear only in the Full table view and only when a target exists, so the compact view
stays as short as Sensibull's.
