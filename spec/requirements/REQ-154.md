# REQ-154: An unsaved builder strategy survives a page reload

Why: a user who builds four legs and reloads the page loses all of it. Measured 2026-10-27 09:50:46: the iron condor was gone and the page said "No draft strategy is open". Owner choice: kept on the server per user (works across devices); the cheaper alternative is the browser only.
