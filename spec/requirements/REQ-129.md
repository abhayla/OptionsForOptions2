# REQ-129: Support lookup of one user's order trail

Why: once real users trade, the first support question is "why did my order not go through?". The answer is in the
audit and order records (REQ-064, ADR-105 tags), but today only a developer with database access can read them. A
read-only, audited lookup answers the question without database access and without exposing secrets.

Example: a user writes "my iron condor only got 3 legs". Support searches Client ID AB1234, opens strategy 41, sees
that Zerodha rejected the 23,300 CE sell for insufficient margin at 10:33, and replies with that, while the lookup is
recorded with the ticket number (AC-2, AC-5).

Decisions: ADR-029, ADR-105. Register row: MR-147.
