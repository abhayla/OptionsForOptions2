# REQ-039: Strategy state machine and exception states

Strategies move through explicit states; every exception explains itself.

Decisions: ADR-019. Sources: M §51, §52; C-file (real Q numbers: spec/traceability/question-register.md); H1 §37 item 13.

**Transition table:** spec/data/domain-model.md §6, approved by the owner on 2026-09-29 (Q240) with two fixes:
Reconciliation Required is left only through a recorded manual resolution (Q222), and Active ↔ Monitoring Paused
happens only when the user pauses or resumes monitoring (a lost feed or an expired Zerodha session never changes the
state).
