# REQ-026: Expected market range input

A user unsure of the outlook can give an expected lower and upper level for a chosen expiry.

Decisions: ADR-005. Sources: T2 #19-#34; Q106-Q111.

**Q208 decided (ADR-042):** that decision sets the scenario-table column step (NIFTY 100, SENSEX 300). The range pick lists keep the 100-point step AC-5 states for both indices (SENSEX strike gap is 100, so every value is a real strike). Discovery wording that uses the range (AC-1, AC-4, AC-8) waits on the legal review (Q211).
