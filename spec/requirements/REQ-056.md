# REQ-056: Multi-leg execution plan and review

The user presses one Execute Strategy button; the engine plans dependency-aware order sequencing.

Decisions: ADR-017. Sources: M §28, §45; C-file (real Q numbers: spec/traceability/question-register.md); H1 §21, §36; H2 §22.

**Open:** Order types, per-leg pricing, tick rounding, timeout/cancel/repricing, MIS/NRML: open (§95). See `spec/open-questions.md`.
**Decided 2026-10-15:** timeout/cancel/repricing → ADR-079 (Q263); MIS/NRML, tick rounding and the per-leg executable
LIMIT ("Execute at current market conditions") → ADR-080 (Q264, Q265, Q268); freeze limits → ADR-081 (Q266);
charges → ADR-082 (Q267); expiry settlement and expiry-day entry → ADR-083 (Q269).

**Findings (spec/findings.md, 2026-10-02):** F-07 - Zerodha's current API order rules for the broker phase: accepted is
not executed; interim statuses are not final; a place_order timeout can leave a live order, so look it up by our tag and
never resend; 10 orders/second, 400/minute, a daily cap (3,000 vs 5,000, unverified), 25 modifications per order;
autoslice returns mixed results and allows at most 10 slices; market and SL-M API orders need non-zero market
protection (AC-10). F-04 - freeze limits differ per broker for the same contract (AC-1).

**Owner decisions (2026-10-19):** AC-4 is reworded to the two-basket rule (ADR-117, fix direction for #390); AC-11 is
the middle-state wording; AC-12 is the market-hours block (ADR-119). **Finding (2026-10-19):** F-50 - Kite's own
basket page shows "Required margin" and "Final margin", order sequence changes the required margin and not the final
one, and for F&O buy options first (bears on AC-3 and the sequence note on the Execute screen). F-54 - the legacy
algochanakya 2026 holiday list is wrong (misses 2026-10-20, lists 2026-10-21); AC-12's calendar is NSE's dated list.

**Findings (2026-10-07):** F-17 - every order sent through a broker API is an algo order under NSE's framework, even one
the user confirms (it must carry an algo tag; algo market orders are not permitted per the NSE FAQ, reported by stream
S1a); F-18 - an algo provider's strategies must run on the broker's servers. How the execution plan reaches Zerodha is
open for owner decision as Q259. F-22 - Zerodha's offsite order execution (a read-only multi-order basket placed by the
user on Kite's exchange-approved order page, our tag per order) is one candidate path.
