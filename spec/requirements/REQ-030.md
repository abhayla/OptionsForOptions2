# REQ-030: Option Chain leg selection and import

Users select contracts in the chain with explicit Buy/Sell and lots, then import them as strategy legs.

Decisions: ADR-007, ADR-016. Sources: M §19; H2 §4; CH1 Q35, chain import; Q43, Q44, Q47–Q54, Q56.
