  text: >-
    The payoff chart draws the At Expiry curve and the Estimated curve on the same axes, labelled "At expiry" and
    "Estimated on <date>" ("now" unless a target date is set, REQ-084). Both curves come from one engine reply for the
    same strategy state, never from two calls that could be for different edits (REQ-034 AC-8).
- id: AC-2
  text: >-
    Hovering at an index level shows both values at the nearest level the engine computed, for example "At 23,480
    (+2.2%): estimated on 21 Oct -Rs 4,696.00 | at expiry -Rs 9,401.00". The browser never interpolates or computes a
    money value between computed points (ADR-008).
- id: AC-3
  text: >-
    When the engine has no Estimated view (an option leg without IV, scenario-calculations section 4), the chart draws
    the expiry curve only, with the reason under the legend. When legs are on different expiries the chart carries the
    ADR-143 line "Worst case: the loss for this strategy can't be estimated."
- id: AC-4
  text: >-
    The chart marks the expected move at plus/minus one and two standard deviations around spot, computed on the server
    by the REQ-027 formula (spot x ATM IV x square root of calendar days / 365). Example (REQ-027): NIFTY 23,047, ATM
    IV 12%, 7 days gives +/-383 points (1 SD) and +/-766 points (2 SD). The days are those to the strategy's nearest
    expiry, or to the target date when one is set (REQ-084).
- id: AC-5
  text: >-
    The chart can overlay open-interest bars per strike for the strategy's expiry - calls and puts in two colours -
    switchable between OI and today's OI change, with the time the OI was read. It uses today's live OI only, no
    history (ADR-066). The overlay is on by default at Standard and Advanced and off at Guided.
- id: AC-6
  text: >-
    When OI is not available for an expiry (not streaming, feed stale), the overlay says "OI not available for this
    expiry" with the reason; it never draws zero-height bars as if OI were zero.
- id: AC-7
  text: >-
    The chart marks the current spot and every breakeven. Zooming in or out asks the engine for points over the new
    range; the browser never extends a curve beyond the points it was sent.

# REQ-083: Payoff chart overlays

Why: a user wants to see today's risk as well as the risk at expiry, and where the market is likely to move compared
with where the strategy loses. Sensibull's chart shows both curves, SD bands and OI bars on one axis (study
2026-10-21). Drawing the two existing modes together is not a third ADR-120 mode; ADR-151 later added the target date.

Register: MR-019, MR-022, MR-023 (DECIDED: the formula is in REQ-027; REQ-034 had no AC for drawing it).

Note for the docs PR: REQ-034 AC-6 is rewritten there to add the ADR-151 what-if inputs (not done in this file).

Decisions: ADR-152, ADR-151, ADR-120, ADR-008, ADR-066, ADR-143.
