# REQ-014: Zerodha Client ID binding and anti-abuse

One Zerodha Client ID belongs to one platform account at a time, with a recovery/transfer path.

Decisions: ADR-022. Sources: M §62; H2 §11; Q82 = C, Q83 = D, Q84 = A, Q87 = A, Q95 = A, Q97 = A.
