# REQ-090: Four index underlyings

Why: users who trade BANKNIFTY or FINNIFTY options would otherwise need a second tool; Sensibull covers all four
indices. The owner chose the four indices and no stock options (ADR-157, a SPEC CHANGE to ADR-001). Index options share
the engine, cash settlement and contract identity already built.

Register: MR-003.

Note for the docs PR: REQ-001 AC-1 ("Only NIFTY (NSE) and SENSEX (BSE)") needs the same change; this file does not edit
REQ-001.

Decisions: ADR-157, ADR-001, ADR-042, ADR-052, ADR-082, ADR-091, ADR-092, ADR-104.
