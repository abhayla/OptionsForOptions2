# REQ-139: Builder header with day change and OHLC

Why: the first thing a planner checks is where the index is and how far it moved today; Sensibull shows it in the
builder header (study 2026-10-21). ADR-152 makes that the default. F-47 records that today's feed decoder drops the
fields this needs, so the server must read them first.
