# REQ-072: Index spot prices for NIFTY 50 and SENSEX

The core's first screen needs the index level: a payoff, its "current" column and every Greek are computed against it.
REQ-054 kept index segments out "until a requirement needs them"; this is that requirement.

Decisions: ADR-050 (identity and segment list), ADR-051 (the core's data proof on the owner's account).
Findings: F-10 (Zerodha's NSE / 1001 is both "NIFTY 50" and a cash row), F-20.
