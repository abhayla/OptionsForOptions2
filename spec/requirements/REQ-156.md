# REQ-156: Compare approaches

Why: one situation usually has several possible approaches, and the owner wants the user to compare all of them on
named criteria and decide (ADR-214 (2a), owner choice "Leader per criterion" over a ranking or a named best option).

Decisions: ADR-214, ADR-003.
