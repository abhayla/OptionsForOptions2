# ADR-213: Index strip socket drop keeps values under the not-live message

## Why
- Sensibull keeps prices on screen and adds a warning when its socket drops; it never blanks them.
- A blank index strip on a socket drop hides the one number a trader looks at first, while the server can read it.

## Alternatives not taken
- Keep ADR-077 as is (values blank on a cold drop).
- Answer LIVE on a drop (the page's own stream is dead; that is the bug the liveness finding guards).
