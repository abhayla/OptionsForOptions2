# ADR-107: Live-run gate on deferred Tier A issues = triage, not "all closed"

## Why
- The literal rule blocked a 1-lot run on gaps it cannot reach (freeze slicing applies only above the freeze limit).
- Quietly reading it loosely would narrow a safety rule without saying so (finding
  process-change-narrows-safety-rule); the owner decided instead.
