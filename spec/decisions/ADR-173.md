# ADR-173: Sensibull first, enforced

Why: ADR-152 and the goal contract already said "read the Sensibull screens first", but nothing checked it, and the
briefs for rows 10-14 carried no Sensibull reference. A rule nobody checks gets skipped; a brief check refuses the
dispatch instead. The owner chose to apply it backwards to every row built so far, so no shipped behaviour differs
from Sensibull without a recorded reason.
