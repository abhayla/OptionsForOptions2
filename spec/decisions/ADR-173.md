# ADR-173: Reference product first, enforced

Why: ADR-152 and the goal contract already said "read the reference product screens first", but nothing checked it, and the
briefs for rows 10-14 carried no Reference line. A rule nobody checks gets skipped; a brief check refuses the
dispatch instead. The owner chose to apply it backwards to every row built so far, so no shipped behaviour differs
from the reference product without a recorded reason.
