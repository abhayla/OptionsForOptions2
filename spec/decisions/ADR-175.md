# ADR-175: Account-opening link and safety explainer on Connect Zerodha

Why: without a Zerodha account no live feature works, so the panel otherwise ends in a dead end; the reference product shows the
same link and explainer. The partner code makes it promotional content of a Zerodha Authorised Person, so the text is
checked for compliance before release.
