# ADR-014: Market-data source: interim Zerodha live data, target licensed NSE+BSE source

## How the decision moved (all dates 2026)
1. 14 Sep, **Q9 = B**: centralized licensed provider; broker APIs only for trading.
2. 15 Sep (T1 #176–#180): TrueData and Global Datafeeds (GFDL) shortlisted; both technically fit, but their normal
   subscriptions do **not** allow showing data to SaaS users — commercial exchange licensing is needed. NSE policy
   governs use, display and redistribution.
3. 20 Sep, **Q171** (T2 #106) + owner (T2 #107): licensed NSE-authorised source is primary; **Zerodha only for
   placing orders and syncing positions**, because Zerodha live data needs a ₹500/month API.
4. **Q172–Q174**: checklist first; TrueData's public Velocity plans exclude API access; ask for a custom commercial
   API quote covering NSE+BSE, index + F&O, real-time + historical, option chain, L1 bid/ask, OI, volume, IV, Greeks,
   1/5-minute + EOD history, priced for 5k/100k/500k users.
5. **Q175/Q176** (owner): emails drafted; the owner **sent the TrueData email** (T2 #113); a GFDL email was drafted for
   sales@globaldatafeeds.in.
6. 22 Sep (owner, T2 #115): TrueData said an **"NSE certificate"** is needed for commercial use. ChatGPT: broadly
   right — commercial display needs exchange approval; ask TrueData exactly which document and who obtains it.
7. 24 Sep, **Q177 (first meaning)**: seven routes (direct NSE, authorised vendors, NSE+vendor hybrid, broker APIs,
   delayed/EOD first, 1/5-minute NSE snapshots, separate execution vs analysis data); recommendation: don't abandon
   live data, also contact NSE (marketdata@nse.co.in). TradingView ruled out (terms).
8. Owner (T2 #119): **option data also comes from BSE**. **Q178 (first meaning)**: NSE + BSE together is a hard
   requirement; prefer one source covering both.
9. **28 Sep, owner decision (T2 #121)**: *use Zerodha's live market data; no historical data for now; guide users
   step by step to get the Zerodha API*, until commercial live data is sorted.
10. ChatGPT's check of Zerodha docs that day (T2 #122, **not verified by us**): the free Personal plan has **no** live
    data; the ₹500/month Connect plan per API key has live WebSocket data and historical candles; Kite Connect data
    **may not be displayed or redistributed on other platforms**; startups building mass-retail products may get Kite
    Connect free — contact Zerodha's API team.
11. **Q177 (second meaning)** — PROVISIONAL: Zerodha live data is the interim V1 source, **subject to written Zerodha
    approval** for this SaaS use. **Q178 (second meaning)**: build a guided Zerodha setup feature (ADR-020).
    **Q179**: the gateway stays vendor-independent — the app never knows the data came from Zerodha.

## Rules
- Never scrape NSE; never expose vendor credentials; never assume broker data may be redistributed.
- Vendor comparison uses one checklist: data fields, history depth, limits, WebSocket capacity, contract master,
  redistribution and derived-data rights, caching/storage rights, per-user fees at 5k/100k/500k, NSE **and** BSE.
