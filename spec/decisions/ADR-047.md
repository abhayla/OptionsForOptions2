# ADR-047: Copy first from algochanakya

## Decision
- Source: `abhayla/algochanakya`, local checkout `D:\Abhay\Ventures\algochanakya`, map pinned to commit `bf9faf7`.
- One map (`spec/technical-design/legacy-reuse.md`) covers backend services, API, models, scripts, tests, frontend,
  Claude skills, docs and tooling, each module with a verdict (COPY, ADAPT, REFERENCE, SKIP), the change it needs and
  any hard-rule conflict with file and line.
- A work item copies the rows it needs when it starts; each copied file names source repo, commit and path (ADR-043)
  and gets this project's own tests.
- When the map and the source disagree (a newer commit), the map is re-checked for the rows in use and re-pinned.

## Alternatives not taken
- Copy everything at once into the repo (untested code in main; legacy code breaks the money and strategy-only guards).
- Search algochanakya each time a module is needed (repeated work and tokens).
