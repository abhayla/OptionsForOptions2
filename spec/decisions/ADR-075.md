# ADR-075: A saved draft keeps its planned entry prices

## Why
- A user reopens a draft mostly to continue the same idea with the same numbers; re-capturing entries on reopening
  silently changes the payoff, which ADR-068 item 1 forbids ("changes only when the user asks to reprice").
- To see the idea "entered now", the user reprices with one action.

## Alternatives not taken
- Re-capture entries from current prices on reopening (today's behaviour): the saved draft would not reload as saved.
