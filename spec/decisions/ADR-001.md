# ADR-001: V1 product scope

## Owner answers
- First message (T1 #1): a website to help customers plan and execute **option selling** strategies — plan in
  advance, see profit/loss, place orders, make adjustments; options + futures; Indian market only; **indexes only,
  NIFTY and SENSEX**; very easy for someone with basic option-selling knowledge.
- **Q8 = Yes** (T1 #17): NIFTY + SENSEX only; leg types Call Buy/Sell, Put Buy/Sell, Futures Buy/Sell; unlimited
  multi-leg combinations.
- **Q13 = B** (T1 #27): public SaaS, not only for existing customers → multi-tenant from day 1. ChatGPT recommended C
  (existing customers / small beta first); the owner chose **B**. Launch is public; an invite-only switch exists but
  is **off by default** and is used only if the compliance review (Q211) or Zerodha's answer (ADR-034) forces a
  limited start (Q216 = A, owner 2026-09-29, ADR-036).
- **Q14 = B** (T1 #29): responsive web from day 1 — desktop for construction/analysis/Option Chain/wide tables/payoff,
  mobile for alerts/monitoring/P&L/review/execution; no native Android/iOS apps initially.
- **Q6 → Zerodha only** (T1 #13 named six brokers; T1 #47 the owner changed it): V1 supports **only Zerodha**. The
  execution layer keeps a clean broker boundary so others can be added later, but none is built now. Q22 (several
  broker accounts per user) is void as a result.
- **Q23 = Yes** (T1 #49): self-directed only — each user connects and trades **their own** Zerodha account; no
  managing others' accounts, pooled money, copy trading, discretionary trading or shared Zerodha credentials.
  Positioning: *Your Zerodha account. Your strategy. Your decision. Our technology.*

## Non-goals (M §94)
Multiple brokers; unrestricted autonomous trading; full quant backtesting; tick-by-tick history for every option;
native apps; unrestricted order terminal; AI trade-advice chatbot; copy trading; pooled money; discretionary account
management; recreating Zerodha's RMS.
