# ADR-199: The default expiry after the close on an expiry day

## Why
- On 2026-10-27 (a NIFTY expiry day) every builder default after 15:30 pointed at contracts that had already expired:
  a ready-made card, the drawer and Learn's "Open in Builder" all loaded legs that could not be priced. A user who
  plans tomorrow's trade in the evening would have to change the expiry by hand every time.
- The spec named only the label of an expiry-day expiry (REQ-135 AC-2), not which expiry is the default after the
  close. The owner chose to roll the default and keep the expired expiry visible in the list.
