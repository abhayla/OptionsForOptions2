# ADR-074: REQ-065 open at the Stage 4 core gate, Verified before Stage 5

## Why
- The response door (REQ-065) took nine rounds in W-069/W-070 and its remainder (#200: module rebinding and seal
  reuse not flagged in CI) is parked. It guards what an API response may contain; it is not a link of the core chain
  (price, engine, order, reconcile, watch).
- Holding the whole core gate on it would delay 4b and 4c by an open number of rounds while Stage 4 has exactly one
  user.

## Alternatives not taken
- The core gate waits for REQ-065 (no exception): more open-ended rounds on #200 before the core can close.
