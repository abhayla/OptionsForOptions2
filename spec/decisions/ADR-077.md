# ADR-077: Browser connection drop shows the last price time

## Why
- A user who sees "not live" next wants to know how old the last numbers are; only the AC-5 message says it.
- Keeping the time, not the price, keeps the rule that no stale price outlives its subscription.

## Alternatives not taken
- Keep the draft label after a drop (it does not say how old the last numbers were).
