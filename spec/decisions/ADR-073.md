# ADR-073: Framework docs pages only in development and test

## Why
- The #148 design puts every API response through one closed door so that only fixed, reviewed template text
  reaches a user (ADR-003 Q226). The framework's `/docs` and `/openapi.json` send free text taken from code and
  cannot pass through it.

## Alternatives not taken
- Serve them everywhere as a named exemption from the door (free text from code would reach the public).
