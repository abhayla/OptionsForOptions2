  "draft", has at least one paper order of a reducing kind (exit, settle, stop) and has a net quantity of 0 on every
  contract. This repairs trades that finished before the store began to write "closed" at the last exit (migration 0049).
  (2) Deleted rows are included: a deleted finished trade that is brought back by Undo (ADR-293) must read Completed,
  not "Running". (3) A strategy with a real broker order is excluded (an execution plan row or an adopted holding);
  real positions are closed by the reconciliation, not by the paper book. (4) The change sets the status only, so it
  runs once, a second run changes nothing, and the dates shown on the Completed list do not move. (5) It is data only;
  it is applied to a database by the normal upgrade, with the app stopped. On the dev database it would close 39 rows
  (27 not deleted, 12 deleted); it has not been applied to any database.

# ADR-315: finished practice trades read Completed

Why: a status rule that only applies to new trades leaves every old finished trade reading "Running".
