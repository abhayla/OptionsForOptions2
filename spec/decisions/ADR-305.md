# ADR-305: the plan box is what the app does

Why: two places could state a profit target for one trade (the rule set and the trade's plan box), and the box always
carried a number the user never typed. The owner chose the simplest rule a user can hold in their head: the box is the
truth for that trade, and an empty Target means no target alert.
