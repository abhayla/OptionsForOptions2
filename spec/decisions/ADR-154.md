# ADR-154: Static-IP plan B, as intent

Why: the owner chose broker-held stop-loss triggers (ADR-153), which may need the static IP the platform does not
have. One platform IP keeps the cost flat as users grow; renting each user an IP passes a monthly fee to every
beginner.
