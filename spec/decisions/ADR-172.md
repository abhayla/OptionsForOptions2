# ADR-172: IV from the bid-ask mid, else the last trade

Why: on a quiet strike the last trade can be minutes old while the quotes move, so an LTP-based IV jumps when the next
trade prints; the mid follows the current market, and the forward is already derived from mids (ADR-061).
