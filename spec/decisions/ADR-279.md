title: 'Two trigger checkers run the same code: live is always on, a test-data checker starts on demand'
decision: >-
  Owner 2026-11-08 ~18:00 IST (GC-ICTRACK, answer A4). (1) The live checker is always on and checks real and paper
  strategies on live prices. (2) A test-data checker, started on demand, runs the same code on scenario data and sees
  only test strategies. (3) Nothing switches between them automatically. (4) When live prices are missing, the live
  checker answers "not checked: prices not live" for each trigger, never a pass and never test data instead.
