# ADR-022: Client ID binding and anti-abuse

## Decision
- Q82: same Client ID on a second account → block normal independent access; offer recovery/transfer; no second trial.
- Q83: hybrid transfer — straightforward cases auto-complete after verification; suspicious/repeated → Admin review.
- Q84: one Client ID → one platform account at a time; no family/business sharing in V1.
- Q87: no attempt to link one human across several legitimate Zerodha accounts; basic anti-abuse only.
- Q95: same Client ID re-auth restores the association; no new trial/customer/entitlement.
- Q96: account deletion keeps only a minimal anti-abuse/entitlement record, subject to privacy/retention policy.
- Q97: never connected to Zerodha → trial tied to the platform account; another unlinked account may get its own
  trial; no aggressive fingerprinting.
