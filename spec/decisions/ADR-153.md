# ADR-153: Stop-loss held at Zerodha as a broker trigger

Why: a stop-loss only helps if it acts when the user is not looking. An alert the user may not see in time does not protect a beginner from a
gap move; a trigger held by the broker does, and it survives the platform being down and the daily 06:00 logout.
