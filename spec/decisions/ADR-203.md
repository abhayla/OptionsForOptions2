# ADR-203: Strategy Chart from Kite history; data errors fixed in the UI round

## Why
- Sensibull's builder has the Strategy Chart (study 016); ours shows "coming soon".
- The data exists on the owner's own Kite Connect connection (F-33), so the only blocker was the display-rights hold,
  which the owner lifted for this chart.
- A wrong number on a trading screen outranks any look difference, so data errors found in the UI round are not deferred.
