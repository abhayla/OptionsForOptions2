# ADR-198: Thirteen builder features get their requirements

## Why
- A documentation audit on 2026-10-27 compared every row of the builder gap list with the spec. About 60 builder and
  drawer features had an acceptance criterion; 13 had none or only part of one, and two rows cited a requirement that
  does not cover them (Funds needed cited REQ-081, whose "funds" are the available funds; the Booked P&L toggle cited
  REQ-140, which never mentions it).
- The owner wants to pick the next features from a list in which every feature has a written rule.
