# ADR-145: Landing page footer text

Why: the spec had no disclosure text and the legal review (Q211) is still open. The owner chose the strictest option:
the same disclosure and risk warning used on every owned channel, plus a plain not-advice line, and no publishing
before Zerodha approves the page.
