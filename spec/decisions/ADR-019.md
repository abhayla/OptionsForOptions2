# ADR-019: Strategy definition vs live state, versions, state machine, timeline and trigger audit

## Owner answers
- **Q127 = C** (T2 #67): keep the original expiry/range, the generated setup, user changes and final configuration.
- **Q134 = C** (T2 #81): choosing an alternative replaces the Builder configuration and keeps the previous one as a
  history state.

## ChatGPT (delegated)
- Q135: history shown as a **simple activity history** (not version management). Q136: restore an earlier
  configuration. Q137: the current one is preserved first. Q138: history kept after execution. Q139: history is
  secondary on the Strategy screen. Meaningful changes are saved automatically; *Undo* after a meaningful change
  (T2 #84).
- **Q189**: Definition (underlying, strategy type, expiry, legs, strikes, actions, quantities, entry/adjustment/exit
  rules, risk limits, preferences) vs Live Market State (spot, futures, LTP, bid/ask, volume, OI, IV, Greeks, P&L,
  margin, payoff, distances, triggers, timestamps, data status). *Market movement can change what the platform tells
  the user, but it cannot change what the user told the platform.*
- **Q190**: every meaningful modification is a new version (what, when, why, who/what initiated, before/after risk,
  orders, resulting position). **Q191**: Proposed → Applied; active only after confirmed execution + reconciliation.
- **Q200**: states Draft · Ready for Validation · Validated · Active · Monitoring Paused · Adjustment Proposed ·
  Execution in Progress · Partially Executed · Reconciliation Required · Completed · Exited · Archived; states decide
  allowed actions (e.g. Reconciliation Required → view yes, execute no; Completed → no orders).
- **Q201**: each non-normal state says what happened, when, what is blocked, what to do.
- **Q202**: immutable timeline (created, connected, validated, entry triggered, orders prepared/submitted/executed,
  adjustment triggered/proposed/approved, partial execution, reconciliation required, …).
- **Q203**: every trigger shows rule, threshold, actual values (e.g. *threshold 300 pts; movement 347; entry NIFTY
  24,850; now 25,197*), timestamp, data source/health, active version, and what followed.
