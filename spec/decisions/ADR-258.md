title: 'Every adjustment is a new starting point for the "already true" rule (F-71)'
decision: >-
  Owner 2026-11-06 ~14:1x IST (question tool, "Reset after each adjustment"). REQ-159's rule (finding F-71: a condition
  already true when tracking starts is shown quietly and opens no record until it has cleared) applies again after
  every adjustment basket (an adjustment as counted by ADR-255): right after the basket fills, each rule is
  re-evaluated; one that is true then is shown "Already true after adjustment N" (quiet, no record) and alerts only
  after it has cleared and crossed again; one that is false starts normally. Rule memory from before the adjustment is
  dropped. Why: live test 2026-11-06 (strategy 88): the sold call entered at delta 0.40 (T-03 limit 0.30) was rolled
  24950 -> 25000 (delta 0.38) and still read "already true when tracking started", so it could never alert after the
  user's new decision.
status: accepted
questions: []
changes: 'Extends REQ-159 / F-71 from entry to every adjustment.'
