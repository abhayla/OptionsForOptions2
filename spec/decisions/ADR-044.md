# ADR-044: Referral success arrives by admin upload of confirmed Zerodha openings

## Decision
- **Q209 = A (owner, 2026-09-29).** Zerodha has no API that reports "an account was opened via your link". The proof
  of an opening is the owner's Zerodha AP account-opening report. The owner's referral link already carries the AP
  code and the referrer's Client ID (link format in the owner's shared identity file, referenced not copied).
- **Flow.** Admin exports the report → uploads CSV (new client, referrer Client ID, opening date) → each row matched to
  a platform user creates one entitlement event: +30 days of Pro (ADR-038), stacking per ADR-025 → unmatched or
  duplicate rows appear in an admin review list → a row is never applied twice.
- **Example.** 12 rows uploaded: 10 match users' Client IDs (each user +30 days), 2 unmatched wait for review.
- Every reward traces to a file row (auditable entitlement events, ADR-023). A click or sign-up alone earns nothing
  (Q61 = A).
- Written into ADR-025 and REQ-021 (AC-7).
