# ADR-108: GC-3 live test - operating rules and expiry

## Why
- The tested domain modules are not what the Kite-basket routes call (F-42); the one harm reachable in this run (an
  early Check, then a second ENTRY while 65 are held) is closed by W-107; the rest needs a manual Kite action or a
  second strategy, which the rules exclude.
- Monday 2026-10-19 is itself the nearest NIFTY weekly expiry (F-43); an unfilled EXIT would go to exchange
  settlement, which the live path does not handle (#279, #352).
