title: 'The Live Strategies card counts open conditions, not inbox rows'
decision: >-
  The Live Strategies card's "N adjustment opportunities" (ADR-230 (2)) counts the strategy's OPEN suggestion records,
  one per triggered condition, not the inbox rows that group them. Example: scenario ADJ-02's first check opens 3
  records (T-01, T-03, T-09) for one strategy; the card reads "3 adjustment opportunities" and links to the one inbox
  row "3 conditions triggered". Dismissing or acting on a record lowers N by one; at 0 there is no mark (singular
  wording at 1).

  (open_counts in backend/ofo_app/routes/adjustment_opportunities.py, merge 431f56a0). No code change.'
