# ADR-042: Scenario column step per index - NIFTY 100, SENSEX 300, set in Admin

## Decision
- **Q208 = A (owner, 2026-09-29).** Step per index, configurable in Admin without a code change.
  Defaults: **NIFTY 100 points** (Q33C), **SENSEX 300 points**.
- **Measured basis (2026-09-29, api.kite.trade/instruments):** NIFTY strike gap 50, lot size 65; SENSEX strike gap
  100, lot size 20; SENSEX nearest-expiry strikes 68,000–83,100. SENSEX trades at roughly 3× NIFTY's level (ratio
  not measured to the decimal), so 300 SENSEX points ≈ 100 NIFTY points as a percentage move, and both tables read alike.
- Every column is a multiple of the strike gap, so columns fall on tradable strikes.
- Lot sizes are never hard-coded; they come from the instrument master (ADR-007 Q36). Examples with quantity 75 are
  illustrative.
- Written into `spec/business-rules/scenario-calculations.md` §4.
