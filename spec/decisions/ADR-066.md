# ADR-066: Historical candles, internal use only

## Why
- On 2026-10-08 `/instruments/historical` returned 344 one-minute candles with OI for NIFTY 50 and for an option, and
  21 daily candles (F-33); the same data recovered the SENSEX expiry close that the live recording missed when the
  laptop's network dropped.
- Showing history to users would add screens and a display-rights question (F-23) to the Zerodha application; using
  it internally adds neither.
