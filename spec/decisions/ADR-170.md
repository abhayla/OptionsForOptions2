# ADR-170: Per-user feeds kept; ask Zerodha for more websocket connections

Why: per-user feeds keep each user's data that user's own (ADR-053, F-23); the limit is Zerodha's to raise, and the
multi-user demo (F-31) is already the place where Zerodha decides what a platform app may do. No spend and no user
setup until Zerodha answers.
