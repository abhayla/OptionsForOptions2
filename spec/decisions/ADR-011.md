# ADR-011: Adjustment engine: configurable rules, playbooks and platform-detected opportunities

## Owner answers
- **Q11 = B** (T1 #23): guided adjustments — detect → explain → possible actions → calculate impact → prepare orders →
  user decides.
- Owner (T1 #175): Positions must not be a plain positions table but a place that **offers adjustment solutions**
  (e.g. take profit on the winning side and re-enter closer to the market); suggestive only in V1, maybe automatic
  later.
- Owner (T1 #177): **make adjustments configurable** — the platform covers all common situations with default options
  based on best practice, and each logged-in user can edit them.
- **Q57 = C** (T1 #179): adjustment rules = **global defaults + per-strategy overrides**.
- **Q149 = C** (T2 #87): even without user adjustment rules the platform monitors and may show *"Adjustment
  opportunity detected"*, always distinguished from *"Your rule was triggered"*; it never silently creates a rule.
- **Q152** (T2 #87–#90): Trigger → pre-defined adjustment → Before/After → user review → prepared orders.
- **Q159 = B** (T2 #91): no user rule + risk area → warning **plus generic possible approaches**, no specific candidate
  trade.

## Rules engine content (ChatGPT, T1 #178, accepted with Q57)
- WHEN: underlying moves X points / reaches a level; distance from short strike or breakeven; a side reaches X% profit;
  strategy reaches X% of max profit or loss; Delta/Gamma/Theta thresholds; IV change or percentile; time to expiry;
  premium; P&L change; any AND/OR combination.
- DO: take profit on a leg, close, roll leg, roll spread, move strike closer/farther, add/remove hedge, add a leg,
  reduce/increase quantity, re-centre, convert strategy, exit, **alert only (no trade)**.
- Control by level: Guided (one simple condition), Standard (a few combined conditions), Advanced (full builder).
- Several rules can trigger together → grouped (*"3 adjustment conditions triggered"*), not three separate alerts.
- Adjustment families found in research (T1 #176): roll untested side / re-centre, roll threatened short strike, roll
  whole spread, convert structure, add hedge, close profitable side, partial close, full exit.

## ChatGPT (delegated)
- **Q160** (T2 #98): four-layer *Adjustment Opportunity* panel — 1 Why detected (condition, strike/BE, distance,
  metric/rule) · 2 Current state (P&L, max P/L, BEs, net Delta/Gamma/Theta/Vega, margin utilisation, DTE, relevant
  IV/OI/LTP) · 3 Possible approaches (no automatic recommendation) · 4 Next step (user picks → Before/After → decides).
- *Why am I seeing this?* names the exact rule and current values (T1 #178).
