# ADR-079: Unfilled basket orders - age and status shown, cancel in Kite

## Why
- ADR-054 keeps every order action on Kite's own page; a platform cancel would be an order sent through the API.
- Repricing while the old order is still open could fill both and double the leg.

## Alternatives not taken
- Immediate-or-cancel basket orders: thin legs would partly fill far more often (with 65 units at the ask, a 2-lot BUY
  fills 1 lot), and whether a basket honours IOC is unverified.
- The platform cancels through the API after the user confirms: departs from ADR-054; whether an API cancel counts as an
  algo order is unknown.
