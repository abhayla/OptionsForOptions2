title: 'The app is hosted on the existing Hostinger Linux VPS with Redis on the same box; the database stays on the Windows VPS Postgres'
decision: >-
  Owner answer 2026-11-11 (question tool, standing direction step 4): "Hostinger VPS, Redis there". Decides Q273. (1)
  The hosted app (API, price-feed process, background watcher, built pages behind nginx on a subdomain) runs on the
  existing Hostinger Linux VPS that already hosts the owner's other sites. No new server and no new spend. (2) Redis,
  the bus between the feed process and the API process (REQ-113 AC-3, ADR-043), runs on that same box (Q273 option
  a), reachable only from that box. (3) The database stays on the Windows VPS PostgreSQL, the one database server for
  all of the owner's apps (ADR-048), reached the way the owner's other hosted apps reach it. (4) The box is shared with
  production sites, so every deploy brief states the box's free memory and disk first and refuses to deploy above the
  owner's limits; staging is deployed and read before production, and production is deployed at most once a day in
  the owner's window. (5) Staging and production keep separate databases, secrets and Kite Connect apps (REQ-126 AC-6).
