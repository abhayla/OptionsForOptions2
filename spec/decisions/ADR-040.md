# ADR-040: WhatsApp OTP is sent through the shared Notifier gateway

## Decision
- **Q220 = A (owner, 2026-09-29).** Q72 (T1 #215) said "I have a separate system for it. I will integrate it later"
  without naming it. That system is the owner's **shared Notifier gateway** (WhatsApp via Wati); no new sender is
  built. Its address and keys live in the owner's shared configuration, never in this repo.
- **Split of work.** The platform owns the code: generation, expiry, attempt and rate limits, verification status and
  time (ADR-021 Q72). The gateway only delivers the message.
- **Template.** A Wati AUTHENTICATION-category template must be approved before production registration can go live.
- **Dev/test.** A stand-in sender logs the code, so registration can be built and tested before the template exists.
- Keeps Q72: WhatsApp proves control of the phone; email OTP would not (Q73: Google email counts as verified).
- Written into ADR-021 and REQ-012 (AC-2).
