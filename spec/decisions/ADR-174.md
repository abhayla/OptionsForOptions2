# ADR-174: No prices without a Zerodha connection, for now

Why: The reference product runs its own licensed feed; OFO2 reads prices only through each user's own Zerodha session. Copying
the logged-out view would need a paid data vendor or Zerodha's written consent, which is a money and licence call.
