# ADR-155: Delayed prices before a broker login

Why: a visitor can plan a strategy only if prices appear before any broker link. Showing exchange prices to
someone without their own broker link is a data-licence question the platform has not answered, so the feature is
specified and built but stays off in production until permission is in writing.
