# ADR-193: Sensibull layout for every screen the spec has, our own brand

## Why
- The study was used to copy what each feature does, never how the screen is laid out, so the builder grew as one
  long column and looks nothing like the reference product traders already know.
- The owner wants a trader-friendly UI now, built on the proven Sensibull layout, without adding product scope
  silently and without copying Sensibull's identity.
