# ADR-046: CI for the API and web layers

## Decision
- A second, project-owned workflow `app-tests.yml` runs the API and web test suites. It triggers only on changes to
  the API/web source trees, their tests, their dependency files, or the workflow itself (path filters), so the many
  spec/docs/domain PRs cost no extra runs.
- The kit's `ci.yml` is not edited (kit rule).
- Context at the decision: the repo is private; 103 Actions runs so far, 45 of them on 2026-09-29; minutes per run
  not yet measured. After the first week of API/web work, the orchestrator reports runs and minutes used by
  `app-tests.yml` to the owner.

## Alternatives not taken
- Make the repository public (free standard-runner minutes; the spec and code would become public).
- Run API/web tests locally only (no CI gate for those layers).
- Keep building only the standard-library domain layer.
