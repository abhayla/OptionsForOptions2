# ADR-056: Rules for proving the core

## Why
- The core shows errors from the first screen, so REQ-065 cannot wait (HANDOVER names the allowlist design after three
  failed denylist rounds).
- A gate judged against another product's numbers (Sensibull) would make that product the authority; ADR-008 makes our
  engine the single source of every number, so the gate checks the engine against its own locked formulas on real
  inputs.
- With per-user feeds (ADR-053) there is no shared feed to load-test with real users before Stage 5; a recorded-tick
  replay tests the same code path now.
- Q232 (owner) put IV and Greeks at Advanced in the strategy table; the chain contradicted it (Stage 0 conflict C-01).
