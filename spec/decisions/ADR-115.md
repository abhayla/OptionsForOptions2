# ADR-115: take kit 1.10.1; merges pin the reviewed sha; kit snapshot cleanup replaces the stand-in

Kit 1.10.1 reached the project as PR #426 on 2026-10-19 and was held until the live 1-lot gate (GC-3L) closed. It
changes three things every session feels: the merge gate needs the reviewed commit's full sha, the kit file guard is
stricter, and the kit's verifier write guard cleans a stopped verifier's snapshots itself, so the project's stand-in
hook is gone. The project's merge helpers carry the sha, and the runbooks name the new form.
