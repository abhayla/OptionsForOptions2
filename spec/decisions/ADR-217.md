title: 'A dismissed adjustment opportunity stays dismissed until its condition clears and holds again'
decision: >-
  When the user dismisses an adjustment opportunity, the same rule on the same strategy opens no new opportunity
  while its condition keeps holding. It opens a new one only after a check finds the condition no longer holding and a
  later check finds it holding again (the same crossing rule as F-71). The inbox keeps the dismissed row with "You
  dismissed this".
status: accepted

  next check" and "Stay dismissed for the day". Asked during GC-ADJ2 step 5 (a builder found that a dismissed flag
  reappeared on the next check, within seconds).'
source: 'spec/requirements/REQ-112.md AC-2; spec/findings.md F-71; GC-ADJ2 contract finding 18.'
consequences:
- 'The check route does not reopen a dismissed rule until a check has found it false; a not-checked rule (no price)
  neither clears nor reopens it.'
