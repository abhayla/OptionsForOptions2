# ADR-189: Kit 1.14.0 lean delivery

Why: the owner approved the kit's lean process for this project (Factory OD-117 to OD-122). Measured before the change:
CLAUDE.md 17,826 bytes against a 2,155-byte allowance, a 62 KB row-review file, a 6.8 KB tracker read by a
SessionStart hook every session, and an ~8-minute local gate per push.

## SPEC CHANGE: text superseded

- ADR-178 (3): "after each row a short status (what a user sees now, expected vs actual, open issues); the full 63-row
  table, the process review and the trend table once per chunk, or when a row runs more than 50% over its estimate;
  the measured expected-vs-actual numbers are generated by a script from commit times and agent transcripts, never
  typed." -> replaced by item (3) above (deliver step 10). ADR-178 also: "process-tool work is frozen until the
  chunk-1 PR, then at most one item per chunk on Sonnet" -> lifted for this change, which the owner ordered.
  ADR-178's "(Opus and mutation tests only for engine, ... order files; Sonnet otherwise)" -> mutation tests are no
  longer a gate (item (4)).
- ADR-181 (1): "one local gate command that every builder and checker runs before reporting PASS and the orchestrator
  runs before every push (ruff ratchet, the guard tests, the repo_scan tests, tests/orchestrator, every database-free
  app test file select_app_tests.py selects, the OpenAPI regenerate-and-compare, the money guard ...)" -> replaced by
  `python tools/ci_local.py`; the ruff ratchet, app tests and OpenAPI compare now run in CI (app-tests.yml). ADR-181
  (2), the dispatch command, stands.
- ADR-171 (8): "no build crosses an unapplied meta review" -> dropped (no meta reviews). ADR-171's "independent
  verifier per row" -> one checker per tier, item (5).
- ADR-112: "a close-out runs tracker_check.py" -> dropped; the build-ahead tracker is read by hand.
- ADR-106 (2): "after round 2 a CRITICAL or MAJOR on Tier A code goes to an independent redesign or parks unmerged" ->
  parks unmerged (no independent redesign). ADR-106 (3): "A per-PR verifier for Tier A; Tier B is verified when its
  requirement closes" -> one checker per item for both tiers. ADR-106 (11): "The fast pre-push set is the guard tests,
  -m repo_scan, the changed files' tests and the ruff ratchet" -> `python tools/ci_local.py`.
- ADR-188 (on the unmerged chunk-4 docs branch, 2026-10-25) item (3): "The local gate stays for every change, Tier B
  included (ADR-181 unchanged)" -> reversed by the owner's 2026-10-26 approval; that branch must take this ADR when it
  lands.
