# ADR-102: Realised P&L from fills, exact and at the paisa

## Why
- One output shape for money (two decimals) everywhere a rupee figure is shown; the engine already holds paise.
- Computing from the fills (the ledger, REQ-057) keeps the platform's own figure independent of Kite's `pnl` /
  `unrealised` / `realised` fields, whose meaning differs by row state (the flat row carries the day's loss in
  `unrealised`, not `realised`).

## Alternatives not taken
- Keep the raw exponent (-130.0): two renderings of the same rupee amount.
- Read Kite's `realised` field: it is 0 on the real flat row, so it would show no loss.
