# ADR-023: Commercial model: 7-day Pro trial, Limited/Read-Only, event-based entitlements

## Decision
- Trial: 7 days full Pro, starts at successful registration (Q88).
- Limited can: see strategies, history, settings, eligibility/referrals/billing; **continue monitoring active
  strategies** (Q89); receive important alerts.
- Limited cannot: create new Pro strategies, use the live detailed Option Chain (Q91), run new Pro simulations,
  use new Pro functions.
- Paid Pro expiry → same Limited model, no special V1 grace period (Q90).
- Owner answers in Chat1: **Q67 = A** (Limited/Read-Only after the trial, not a hard block; the user can still log
  in, view strategies and history, manage settings, see eligibility, refer someone, subscribe, connect/manage
  Zerodha); **Q90 = A**; **Q91 = A**.
- **Safety exception (Chat1, after Q91):** monitoring an already-active strategy is an exception to the rule that
  Limited users get no live data, because removing risk visibility from a live position would be unsafe.
- Chain behind the Pro gate may show a static preview labelled **Sample · Not Live** (Q92).
- Historical records/results accessible indefinitely; new simulations stay Pro (Q93).
- Gated feature click → contextual message: *Subscribe to Pro* / *Check Free Eligibility*; no aggressive popups.
- **Entitlement engine** (§64): never `free_user = true`. Sources: Trial Pro · Direct Zerodha Customer Pro ·
  Referral-earned Pro · Paid Monthly Pro · Paid Annual Pro · Expired/Limited. Stored: source, start, expiry,
  status, reference, audit data.
- Separation (§83): Pro but broker disconnected; Limited but monitoring an active strategy; Active strategy while
  Zerodha session expired; Reconciliation Required while subscription active — all valid combinations.
