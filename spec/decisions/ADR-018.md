# ADR-018: Reconciliation and existing positions

## Owner answers
- **Q24 = B** (T1 #51): on connect, fetch open positions, suggest possible multi-leg structures; the user chooses
  *Add to existing strategy · Create a new strategy · Leave as standalone*; once grouped it is monitored. A standalone
  position is not monitored and gets no platform order (ADR-002: every order belongs to a strategy); acting on it
  means grouping it first. No automatic
  grouping.

## ChatGPT (delegated, T2 #130)
- **Q196**: reconcile after execution, after reconnect, at app start/resume, periodically for active strategies, on
  broker/order events; on difference: *"⚠️ Position mismatch detected"* and stop assuming.
- **Q197**: outside changes (e.g. strategy says Sell 25,000 CE × 50, Zerodha shows × 25) are shown side by side and
  recorded as an external change.
- **Q198**: manual reconciliation choices — *Adopt actual broker position · Review and modify strategy · Close/
  reconcile through a prepared order · Mark as requiring attention*; no casual "ignore"; audited.
- **Q199**: *"🔴 Execution blocked — strategy position needs reconciliation."*
