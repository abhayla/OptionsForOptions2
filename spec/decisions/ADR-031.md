# ADR-031: Source-of-truth order and numbering of new product questions

## Decision
- Order when two sources disagree: 1 `spec/decisions/` (owner decisions) → 2 other `spec/` files → 3
  `docs/reference/chatgpt/` → 4 technical preference. This is the handoff's own §101 order with the imported
  decisions now living in `spec/`.
- New product questions: **Q204+**, listed in `spec/open-questions.md` with the question, recommended answer,
  reason and the owner's final decision (continuation file's final instruction). Each answer → next ADR, same turn.
- Two locked requirements that genuinely conflict: stop, name the conflict, ask one question, record the answer.
