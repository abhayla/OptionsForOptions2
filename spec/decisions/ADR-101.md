# ADR-101: Zerodha money figures rounded to the paisa at parse

## Why
- Zerodha's JSON carries binary-float noise (68498.85000000001, 68498.84999999999). Kept unrounded, an exactly
  sufficient balance reads as a shortfall on the screen and at the gate, which tells the user something false.
- Rounding at one place, the parse point, keeps every later figure exact (ADR-008) and gives one rule to test.

## Alternatives not taken
- Keep the noise (old rule): blocks or flags baskets that Zerodha would accept.
- Round only for display: the gate and the screen could then disagree.
- Round needed up and available down: the same false shortfall at exactly equal amounts.
