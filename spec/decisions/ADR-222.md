title: 'Every number a calculation uses is a setting with a default, edited on one admin Settings page, never typed in code'
decision: >-
  (1) No rupee amount, rate, percentage or threshold that changes a figure a user sees is typed in code. Each is a
  setting with a default value, the date it was set and who set it. (2) One admin Settings page lists them by group
  (Charges, Adjustments, Detection, Scenario columns, ...) and lets the admin (owner) change a value; every change is
  audited, and a calculation always uses the value in force at that time. (3) Defaults: the charge rates stay Zerodha's
  published F&O rates (ADR-082; brokerage Rs 20 per executed order); a per-leg cost allowance, where a calculation needs
  one, defaults to Rs 20 per order on each side (Rs 40 for a leg closed and reopened) until the owner sets another.
  (4) Users never edit these settings; they edit only their own playbooks and plans (REQ-158..161).
  (5) Owner clarification 2026-10-31 ~23:30: admin Settings hold only APP-WIDE values that apply to every user
  (charges, pricing inputs such as the risk-free rate, exchange and broker facts, billing, speeds, scenario and
  display defaults). ADJUSTMENT preferences (alert distances, approach strike rules and roll distances, playbook guard
  defaults, the cost allowance per leg, compare ranges) are PER USER and live on the Adjustments screen in their own
  tab; each user starts from the platform default and changes only their own (REQ-168).
  (6) Owner answer 2026-10-31 ~23:40 (question tool, "Prefs tab + playbooks"): the Adjustments screen's Preferences
  tab holds the values that apply to ALL of a user's strategies (short-strike delta for approach strikes, roll
  distances, the alert distance for a strategy with no playbook, the Compare chart range and move columns, any cost
  allowance); stage-by-stage numbers (stop, target, maximum adjustments, liquidity limits, trigger thresholds) stay
  inside each playbook. No value is held in both places.
  (7) Owner answer 2026-10-31 ~23:45 ("Admin sets defaults"): the admin Settings page has an "Adjustment defaults"
  group holding only the STARTING value of each adjustment preference. A user who has not changed a value follows the
  admin default in force (an admin change moves them); a user who changed it keeps their own.
  (8) Owner answer 2026-10-31 ~23:50 ("Remove it"): there is NO per-leg cost allowance. The Rs 40 COST_PER_LEG is
  deleted once T-19 uses the cheapest adjustment's engine-priced cost (ADR-221); this supersedes the per-leg allowance
  default in (3) and the "any cost allowance" in (6). Real brokerage stays the Charges group's Rs 20 per order.
  (9) Owner answer 2026-10-31 ~23:55 ("Right away, plans kept"): a changed setting or preference applies at the next
  check to every tracked strategy; a strategy's saved plan (REQ-161, copied when tracking started) is not changed by
  it; every alert line names the value it used.
  (10) Owner answer 2026-11-01 ~00:00 ("Admin uses the editor"): the admin changes a SYSTEM playbook in the same
  step-by-step playbook editor and saves it as a new version with history and audit; users still only copy system
  playbooks. The Settings page does not repeat playbook numbers.
