# ADR-028: Notifications

## Owner answer
- **Q25 = B** (T1 #53): include **WhatsApp** in V1 alongside in-app, push and email.

## Priority matrix (T1 #52–#54)
| Event | In-app | Push | Email | WhatsApp |
|---|---|---|---|---|
| Strategy created | ✓ | — | — | — |
| Enters watch zone | ✓ | ✓ | — | — |
| Adjustment opportunity | ✓ | ✓ | optional | ✓ |
| Exit condition reached | ✓ | ✓ | ✓ | ✓ |
| Order rejected/failed | ✓ | ✓ | ✓ | ✓ |
| Daily strategy summary | ✓ | optional | ✓ | optional |

Open: provider, WhatsApp opt-in/consent, quiet hours, templates, escalation, dedupe, rate limits, audit, retry.
