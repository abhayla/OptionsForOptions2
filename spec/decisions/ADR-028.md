# ADR-028: Notification channels and priority

## Decision
| Priority | Channels |
|---|---|
| Info | in-app |
| Watch | in-app + push |
| Action opportunity | push + in-app + possibly WhatsApp |
| Exit / risk / order failure | push + email + WhatsApp + in-app |

Open (§56, §95): provider, consent, quiet hours, templates, escalation, dedupe, rate limits, audit, retry.
