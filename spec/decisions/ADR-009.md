# ADR-009: Unified rule engine; V1 automation is Alert + Prepare Orders

## Decision
- One rule-engine concept for entry, adjustment, exit and future controlled automation (Q138).
- V1 entry conditions: immediate, market reaches level/range, premium target, volatility condition, time window.
  Compound AND/OR to be supported later (Q139).
- Exit conditions: profit target, max loss, time exit, underlying level. Action = alert + prepare exit orders (Q140).
- Trigger inputs include underlying level/move, distance from strike/breakeven, premium, P&L, DTE, IV, IV percentile,
  Greeks, strategy-level thresholds (§14).
- **V1 automation = Alert + Prepare Orders**: condition → alert → exact multi-leg orders prepared → user reviews →
  user executes. No unrestricted autonomous trading (Q141). Architecture allows controlled automation later
  without redesign (Q142).
- Exit and adjustment plans are **optional**; strategies without them are still monitored (§15, Q153).

## Superseded
Both earlier handoffs said *"Every strategy has an explicit exit plan"* (15 Sep §14, Latest §15). The comprehensive
handoff's later clarification (§15) and Q153 make exit/adjustment plans optional. The later decision wins (§101).
