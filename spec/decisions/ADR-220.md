# ADR-220: Server roles, calculation speeds and the pricing model

## Why

On 2026-10-31 the owner asked how the app holds at 1,000 / 10,000 / 50,000 users, how it compares with the reference
product (Sensibull), and whether the maths can run less often. The reference product splits its server into four
services (maths, orders and login, saved data, live prices) and re-posts its builder every 30 seconds. We keep the
same split of jobs, under the owner's names, without four separate products, because one owner and AI builders on one
shared 8 GB machine cannot run four deploy pipelines.

## The roles

| Role | What it does | Copies | Reference equivalent |
|---|---|---|---|
| api | Screens, saved data, settings, history; the browser's only door | 2 or more (REQ-164) | backend + parts of compute |
| maths | The one engine (ADR-008) | 1, more when busy | compute ("oxide") |
| user orders | Zerodha login, order checks, basket, orders, matching | 1 | orders and login ("pluto") |
| liveprices | The only Kite live connections, fanned out (F-59, REQ-113) | exactly 1 | WebSocket relay |
| background | Per-option figures, playbook checks, alerts (REQ-050, REQ-115, REQ-165) | 1, more later | its compute cache |

## The calculation speeds

| What | Recomputed when | Default |
|---|---|---|
| Per-option figures | that option's price changes | at most once a second, once for everyone |
| Strategy open on a screen | one of its prices changes | at most once a second, full table (ADR-068) |
| Background checks, no screen open | one of its prices changes | at most once a second, light sums only |
| Saved draft not open | someone opens it | never in the background |

Example of the safety valve: on a crash morning maths falls behind, so every screen moves to 2-second and then
5-second figures with "as of 09:21:14" shown, instead of the app freezing; it returns to 1 second when the load drops.

## Not decided here

- When to buy a separate machine (a spend decision, asked when a separation line is crossed).
- Speed as a plan feature (owner: not now).
- Changing how theta is shown (asked only if the comparison in (4) finds a gap above Rs 5 per lot per day).
