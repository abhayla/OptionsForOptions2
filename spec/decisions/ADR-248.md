title: '"Suggested for you" ranks only the approaches within the user''s limits, by cost / credit by default, and every card states what it costs'
decision: >-
  Owner 2026-11-05 ~00:4x IST (question tool, "Cost / credit (Recommended)"): the default ranking key for "Suggested for
  you" on a strategy is cost / credit (most credit, or least debit, first). Only approaches that pass the strategy's
  limits in force are ranked (roll-debit limit, liquidity / OI minimum, and no approach that moves a long leg outward
  while a tested-side alert is open); the rest are listed under "Not offered now" with their reason. Each suggested card
  shows the key used and its costs: probability of profit before -> after, max loss change on each side, P&L at -2 % and
  +2 %. The other keys (worse-side max loss, P&L if NIFTY moves 1 % toward the tested side, P&L at +1 % / -1 %, max
  profit, probability of profit after) stay available for each user to pick. Basis, measured on strategy 82 (round-10
  mockup, numbers from the live chain 4 Nov 15:12): 5 of 9 approaches pass the limits; cost / credit puts first the iron
  fly (credit Rs 9,532.25, max loss smaller by Rs 9,348.22) and the untested put spread roll up (credit Rs 3,900, max loss
  smaller by Rs 3,746.45), the only key whose two picks can both still end in profit and both cut max loss; its cost:
  probability of profit 50.2 % -> 17.8 % / 33.9 %. Decision support only (ADR-003). As ADR-245, a default each user and
  each strategy can change.
