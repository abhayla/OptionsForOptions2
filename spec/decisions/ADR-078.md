# ADR-078: A development database for live runs

## Why
- Tests written for an empty database failed locally after every live session, and verifiers had to discount those
  failures by hand; a second database separates the two without a destructive reset after each live run.

## Alternatives not taken
- One database with a scripted reset after each live run (a destructive step every time).
- No change (local database tests unreliable after live work; CI the only judge).
