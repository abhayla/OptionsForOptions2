# ADR-162: Automatic P&L stop-loss by the platform

Why: a beginner's real stop is usually a loss amount, not an index level, and the owner wants it to act without the
user present. Zerodha cannot hold a P&L condition, so the platform must send the exit; that makes it server-sent
trading, which carries the static-IP, algo-registration and server-uptime dependencies named above.
