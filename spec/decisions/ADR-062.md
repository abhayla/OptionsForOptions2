# ADR-062: Save Draft stores strategies durably

## Why
- No requirement said strategies are stored durably (searched: Save Draft, persist, saved draft); REQ-067 AC-1 names
  Save Draft as a step of the first end-to-end slice.
- Real case: an Iron Condor built in the app existed only in memory; a server restart lost it.
