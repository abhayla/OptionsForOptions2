# ADR-180: One-time manual merge of PR #525

Why: everything the gate protects (green CI, review coverage of the merged head, nothing from main lost) was checked by
hand on the exact head; waiting for a kit upgrade would gain no safety and would make every chunk-2 pull request stack
on an unmerged branch.
