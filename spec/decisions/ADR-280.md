title: 'What each of the 12 new iron condor triggers measures (T-04, T-05, T-06b, T-08, T-11b, T-11c, T-12, T-14t, T-14v, T-15, T-20, T-20b)'
decision: >-
  Owner delegation 2026-11-05: decided under "go with your recommendation" (strategy behaviour), GC-ICTRACK
  2026-11-08. The playbook labels name the idea; this row fixes the number each trigger compares, so the screen and
  the background worker give the same answer. Every value is exact Decimal from the one engine (ADR-008); a missing
  input answers "not checked" with its reason, never a pass. Limits are the playbook's per-stage values.
  (1) T-04 net delta per lot: |net position delta in lots| / lots of the largest leg, the same measure as S-02
  (adjust_ratios.net_delta_per_lot); fires at >= the limit (0.15 = 0.15 delta per lot).
  (2) T-05 one side's value vs the other: each side's value = (its short legs' LTP minus its long legs' LTP) x units,
  for the call side and the put side; value = the larger / the smaller; fires at >= the limit (3 = one side three
  times the other). A side worth 0 or less, or any leg unpriced: not checked.
  (3) T-06b loss vs credit: credit = the open legs' net entry premium (SELL entry minus BUY entry, x units); value =
  loss / credit (loss = minus the whole-trade P&L, 0 when in profit); fires at >= the limit. No credit (0 or a debit):
  not checked.
  (4) T-08 leg stop: the highest LTP / entry over the SOLD legs; fires at >= the limit (2 = a short at twice its
  entry). Any short unpriced: not checked.
  (5) T-11b India VIX up today: (VIX now - VIX previous close) x 100 / previous close; fires at >= the limit (10 %).
  (6) T-11c: the India VIX percentile over the last 250 trading days (ADR-277 (2): share of those daily closes at or
  below today's VIX, x 100); fires at >= the limit (80). SENSEX: not available (no SENSEX volatility index).
  (7) T-12 move since entry in expected moves: one SD = ExpectedMove(entry ATM IV, calendar days from the entry day
  to expiry).exact_points(entry spot); value = |spot - entry spot| / SD; fires at >= the limit (1 SD).
  (8) T-14t theta vs premium left: the position's theta per calendar day in rupees x 100 / premium left; fires at
  <= the limit (decay too slow to be worth holding). Premium left 0 or less: not checked.
  (9) T-14v vega risk: the loss a +1 volatility-point rise would cause (minus the position's vega in rupees, 0 when
  vega is positive) x 100 / max profit; fires at >= the limit.
  (10) T-15 margin used: this strategy's margin blocked x 100 / (that margin + Zerodha's available margin, equity
  net); fires at >= the limit (80 % of the account's margin room in use). Margin or available not stated: not checked.
  (11) T-20 levels: fires when spot crosses a level watch the user set (the existing watch rules, ADR-242); no level
  set: not checked with that reason. No second level store.
  (12) T-20b trending: ADX(14) on daily index candles; fires at >= the limit (25 = trending, bad for a range trade);
  20 or less is named range-bound, between is neither.
