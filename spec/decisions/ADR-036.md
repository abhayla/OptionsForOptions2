# ADR-036: Launch is public; invite-only switch off by default

## Decision
- **Q216 = A (owner, 2026-09-29).** At Q13 ChatGPT recommended C (existing customers first, public later); the owner
  answered **B** (T1 #27). The spec had carried C's "small beta first". That line is removed.
- An admin **invite-only** switch limits registration to invited users. Default **off**. It exists so that a limited
  start forced by the compliance review (`spec/open-questions.md` Q211) or by Zerodha's answer (ADR-034) needs no new
  code.
- Written into ADR-001 (Q13) and REQ-003.
