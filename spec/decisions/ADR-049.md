# ADR-049: Frontend styling

## Decision
- Toolkit: Tailwind CSS 4 through the `@tailwindcss/vite` plugin; configuration copied from algochanakya's `frontend/`
  and changed to our tokens.
- Look: neutral-dominant, one accent (cobalt blue), small readable type, no decorative gradients; detail pages use a
  sticky in-page anchor navigation over flat section cards; big tables have a sticky header row, compact rows,
  chip filters with visible state and mobile column priority.
- Reserved colours: Green Healthy, Yellow Watch, Orange Adjustment opportunity, Red Exit condition reached mean strategy
  health only (ADR-010); data availability and errors use other visual cues.
- Not copied: any Zerodha or Kite branding, logo or theme file.

## Alternatives not taken
- Plain CSS with hand-written variables (more code to write, less to copy).
- A component library such as PrimeVue or Vuetify (heavier dependency; its look would need bending to the references).
