title: 'An exit that leaves a sold leg unprotected shows a factual warning; the user can still confirm'
decision: >-
  Owner 2026-11-06 ~14:0x IST (question tool, "Warn, user confirms"). When the legs a user is about to exit (paper
  today, real orders later) would leave a sold option with no bought option of the same type protecting it, the exit
  confirm list shows one warning line before Confirm, in facts only (ADR-003): which leg becomes unprotected, the max
  loss before and after ("no fixed maximum" when unlimited) and the margin needed before and after, e.g. "After this
  exit, NIFTY 17 Nov 25100 CE is sold with no protection: loss has no fixed maximum; margin needed Rs 70,424 ->
  Rs 1,65,945." Confirm stays enabled; nothing is blocked. Why: live test 2026-11-06 (strategy 86) exited the bought
  25300 CE in one click with no sign that the 25100 CE became naked (margin 70,424 -> 1,65,945).
status: accepted
questions: []
changes: 'Adds a warning to the paper exit confirm list (ADR-207 (2)) and later the real exit path.'
