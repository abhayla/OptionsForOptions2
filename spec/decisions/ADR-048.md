# ADR-048: Test database for local runs

## Decision
- Server: the Windows VPS PostgreSQL that GLOBAL.md names as the home of all app databases; reached from the laptop
  only through the existing tunnel. No Docker, WSL or local PostgreSQL install on the laptop (owner rule).
- Isolation: database `ofo_test`, role `ofo_app` (LOGIN, NOSUPERUSER, NOCREATEDB, NOCREATEROLE, CONNECTION LIMIT 5,
  `statement_timeout = 30s`, `idle_in_transaction_session_timeout = 60s`), CONNECT and TEMPORARY revoked from PUBLIC
  on `ofo_test`; the role is granted nothing on other databases and is not a member of the owner role or of
  `pg_write_all_data` (W-051 adversarial review, 2026-10-02).
- Load: functional tests only; anything measuring throughput runs in CI or not at all.
- CI: `app-tests.yml` starts its own `postgres:16` service, creates the same non-superuser role, and runs the proof
  as that role.

## Alternatives not taken
- CI only (no local database runs).
- A native PostgreSQL install on the laptop.
