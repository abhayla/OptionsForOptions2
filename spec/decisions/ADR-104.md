# ADR-104: Eligibility comes from Zerodha's instrument list and margin reply

## Why
- The gate (REQ-059) already refuses every leg with no recorded eligibility, but nothing recorded one, so in a real
  run every leg would be refused. AC-3 names "what Zerodha data allows" without naming the data; ADR-016 points at
  the instrument master and Zerodha's order response, which are the two sources used here.
- Using only Zerodha's own answers keeps AC-4: the platform does not guess Zerodha's risk rules.

## Alternatives not taken
- Ask Zerodha per contract before every save: there is no single "is allowed" API (ADR-016), and a margin call per
  leg on every save costs a request each time.
- Treat "the list carries the row" as enough: expired contracts stay in the list (F-33).
- Accept intraday additions without a load: the platform would then trust a contract it never read from Zerodha.
