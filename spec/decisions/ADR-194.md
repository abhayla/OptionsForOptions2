# ADR-194: Compact P&L table by default, full strategy table one switch away

## Why
- ADR-193 asks for Sensibull's layout; Sensibull's P&L table is four columns, with Greeks on their own tab.
- REQ-035 and ADR-008 s4 lock one wide table with every column shown, from the owner's "nothing hidden" rule.
- The owner chose both: Sensibull's compact look by default, the full table never more than one click away.
