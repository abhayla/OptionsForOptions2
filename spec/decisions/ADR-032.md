# ADR-032: Strategy preferences

## Owner answers
- **Q112** (owner, T2 #35): in **User Preferences** the user states preferred strategy types (e.g. Iron Condor, or
  Iron Condor + Short Call); after the range is chosen, show valid setups of those types, a combination when several
  are chosen; never force an invalid one; still *"Strategies you could consider"*.
- **Q113 = B**: preferred section first; if none valid, say so and show other compatible strategies as alternatives.
- **Q114 = B**: asked at onboarding + *Settings → Strategy Preferences* (add/remove).
- **Q115 = A**: all selected preferences have **equal priority** (no ranking).
- **Q116 = C**: visual strategy library — cards with name, simple payoff/risk picture, short description, *Prefer this*.
- **Q117 = C**: all strategies listed, labelled Beginner / Intermediate / Advanced; any can be chosen.
- **Q118 = C**: before saving, the user explores how it profits/loses across levels, max P/L, breakevens, margin,
  typical market view.
- **Q128 = B**: in the Builder preferences are guidance only. **Q129 = B**: alternatives shown at meaningful changes.
  **Q130 = C**: meaningful = structural (leg added/removed, structure changed) or material risk change (max loss,
  breakevens, payoff shape, effective range). **Q131 = C**: a persistent *Related to your preferences* area + a
  notification only on a meaningful change. **Q132 = C**: clicking one shows a preview with *Review setup*.
  **Q133 = C**: the current strategy stays the one active Builder strategy; the alternative is reviewed separately and
  becomes active only via *Use this setup* (then Q134, ADR-019).
