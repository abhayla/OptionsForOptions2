# ADR-051: Prove the core's live-data half on the owner's own account

## Why
- ADR-030: "prove live data works on real input first". As of 2026-10-07 no real price has ever passed through the
  engine (master plan A1); the Zerodha written answer asked for under ADR-034 has no date.
- Stage 1 found no rule against a Zerodha client using Kite Connect data privately for themselves; Kite's terms bar
  public display and redistribution (F-23), which this decision does not do.
- Orders are excluded because NSE treats every order sent through a broker API as an algo order, even a user-confirmed
  one (F-17), which needs its own decision (Q259).

## What is allowed
- The owner's Kite login, live quotes for NIFTY and SENSEX options and index spot, the basket margin call, the
  WebSocket feed, and storing the responses (without personal data) as test fixtures.
- Our engine and one screen on those inputs, seen by the owner only.

## What stays blocked (ADR-034 unchanged)
- Live data for any other account, the public site, the "set up your own Zerodha API" guide (Q178), any order.

## Alternatives not taken
- Wait for Zerodha's answer (the core stays unproven for an unknown time).
- Data plus one real test order now (premature: Q259).
