# ADR-060: Build on the owner's Kite app until demo-ready, then apply

## Why
- Zerodha's reply to ticket 403947 (2026-09-29) asks for a workflow, a demo video, a link with demo credentials, the
  API and market-data endpoints and, if advisory, an RA number, and says "permissions are granted only for
  production-ready platforms" (F-31). Waiting for an answer before building cannot end: the answer needs the build.
- ADR-051 already proved the data half may run privately on the owner's account; this extends it to the whole core.

## What stays unchanged
- No live data from the owner's app reaches any other account or the public site (F-23); others see "Sample · Not
  Live" (Q92).
- Our server sends no orders (ADR-054); the owner places the basket on Kite's page.
- Whether basket orders are non-algo for other users (Q259) stays open for Zerodha.

## Alternatives not taken
- Wait for Zerodha (blocked forever, since Zerodha wants the demo first).
- A licensed data vendor now (paid, and vendor replies are still pending).
