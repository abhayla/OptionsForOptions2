# ADR-169: Zerodha connection by login only, no own-app setup

Why: Sensibull connects by a Zerodha login alone; an own-app walkthrough asks every user for developer steps and,
below Rs 2,000 monthly brokerage, a Rs 500 app charge (F-31 note), and would be thrown away once Zerodha approves one
platform app (Q210).
