# ADR-187: take kit 1.12.0; grafts off on the merge path; no UTF-8 prefix; chunk size limit lifted

Kit 1.12.0 reached the project as PR #546 on 2026-10-25. The two changes every session feels: the merge gate now lands
pull requests of 300 or more files by reading local git, and kit tools no longer crash or misread text on a Windows
console. The Tier A review found that the new local-git path trusts git grafts, so the project's merge helpers switch
grafts off until the kit does.
