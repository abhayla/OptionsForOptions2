# ADR-192: Save As pre-fill fits the 20-character name limit

## Why
- Two owner decisions clashed: REQ-134 AC-2 pre-fills "<name> copy", and ADR-183 limits every typed name to 20
  characters. For any original name of 16 or more characters the pre-filled name was refused by the server.
- The owner chose to shorten the original part so one click always gives a valid name.
