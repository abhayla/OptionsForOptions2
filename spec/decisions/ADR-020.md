# ADR-020: Zerodha connection, status, drafts without Zerodha and guided setup

## Owner answers
- **Q79 = A, revised** (T1 #229–#233): connection is completely optional until a broker-dependent function (execution,
  live positions/orders/account data, direct-customer eligibility). Prompt: *"Connect your Zerodha account to continue.
  We'll use your Zerodha account to verify availability, check margin and prepare/execute your strategy."*
- **Q80, revised** (T1 #232–#233): after registration open **Home** directly; no Zerodha step in onboarding.
- **Q94 = A** (T1 #261): disconnecting keeps the strategy and history; broker features stop until reconnect.
- Owner (T1 #265): the Zerodha session **expires every day** (morning) and needs re-authentication; session expiry is
  not identity loss (ADR-022).
- Owner (T2 #121) → **Q178 (second meaning)**: a **guided Zerodha API setup** feature: open Zerodha Developer Console →
  create the API app → enter our redirect URL → generate credentials → connect → authorise → test; then *"✅ Zerodha
  connected · 🟢 Live market data connected · 🟢 Positions synchronized"*; *"Historical market data: Not currently
  available"*. Also under **Settings → Broker & Market Data → Zerodha**.
- Never request the user's Zerodha password, PIN or OTP (owner's continuation prompt, T2 #1).

## ChatGPT (delegated)
- **Q181**: four separate statuses — account connection, live market-data connection, position/account sync,
  order-execution readiness; states Connected / Partially connected (says what to fix) / Disconnected (guide).
- **Q183**: automatic reconnect → validate + resync → resume monitoring; reconnecting **never** places an order.
- **Q185**: Zerodha not required to create a strategy; drafts marked *"Draft — Live data not connected"*; no fake
  prices. **Q186**: without Zerodha — choose underlying/strategy, edit legs, set rules, save ✅; live prices, Greeks,
  P&L, live margin, executable orders ❌; risk validation limited. **Q187**: connecting never activates, prepares or
  executes. **Q188**: drafts recalculate automatically; strikes/structure never changed; unsuitability shown as
  information.
