# ADR-098: AC-4 bar for W-080

## Why
- The remaining bypass needs code written on purpose to forge a trusted file name; it cannot happen by accident, and
  no app code sends orders. A name list cannot close every compiler (finding guard-by-banned-shapes), so the
  structural fix is planned separately instead of holding the basket back.
