# ADR-150: Strike moves allowed now; rule-placed strikes held for the legal check

Why: the 2026-10-21 Sensibull study showed one-click strike moves and rule-placed ready-mades as the builder features
beginners use most. A move of strikes the user picked states no view of the platform's, so ADR-055 (1) does not stop
it; a strike the platform places by itself could be read as a recommendation under SEBI's research-analyst rules, so
it waits for the written legal answer that ADR-055 already waits on.
