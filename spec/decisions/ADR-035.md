# ADR-035: Expiry scenario P&L uses the entry price; LTP only for live P&L

## Decision
- **Q215 = A (owner, 2026-09-29).** Expiry columns: entry price. Live P&L column: LTP.
- **Why it was asked.** At T1 #95 the owner described the expiry cell using "the current market price, which is
  38.2"; ChatGPT answered at #96 that expiry scenarios use the entry premium and the LTP belongs to live P&L; the
  owner replied only "Can you continue?" (#97). The spec had recorded the entry-price rule as the owner's own.
- **Worked check.** BUY 22,800 PE, entry ₹42.50, LTP ₹38.20, Quantity 75, NIFTY 22,000 at expiry →
  `(800 − 42.50) × 75 = ₹56,812.50`. Using the LTP would show ₹57,135, which overstates the result by ₹322.50.
- Written into `spec/business-rules/scenario-calculations.md` §1.
