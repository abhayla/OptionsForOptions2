# ADR-161: Manual P&L, FII/DII data and native apps

Why: the owner chose Sensibull's scope for all three. Manual P&L stays visibly separate from broker-verified P&L so
the exact-from-fills rule of ADR-102 still holds for the number Zerodha can confirm.
