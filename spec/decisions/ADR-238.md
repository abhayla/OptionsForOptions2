title: 'Iron condor exit and reduce approaches A-24, A-25, A-26, A-27, A-35: legs, limits and refusals'
decision: >-
  Technical definitions for GC-IC1 step 2 (owner scope 2026-11-03 "Full playbook": every approach the approved iron
  condor playbook lists must work), decided by the orchestrator under the owner's standing rule that technical calls
  are not asked; the defaults below are the catalogue's own numbers (docs/research/adjustments-catalogue-2026-10-30.md
  Part 2) and every one is a user or playbook value the owner can change.
  (1) A-24 "Take profit, whole strategy" closes every open leg at the planned prices: the same trades as A-31, built by
  the same code path (one builder), shown as its own column because the playbook names the profit route separately.
  (2) A-25 "Close X% of lots" closes X% of every leg's lots, X = the user preference adjustments.partial_close_percent
  (default 50, catalogue A-25 and S-12). Refused, naming the leg, when X% of any leg's lots is not a whole number.
  Example: a 1-lot condor at 50% is refused (half of one lot is not a whole lot); a 4-lot condor closes 2 lots of each
  leg.
  (3) A-26 "Close the untested side for profit" buys back the untested short only (catalogue A-26 "buy back the far
  short"; its wing stays) when that short's price has fallen by at least D% from its entry, D = the user preference
  adjustments.untested_decay_percent (default 80, the low end of the catalogue's 80-90%, so it is offered earlier).
  Otherwise refused with the decay reached. Example: entry Rs 40, now Rs 8 = 80% decayed -> offered; Rs 9 -> refused.
  (4) A-27 "Buy back cheap shorts" buys back every short whose price is at or below the playbook's T-09 threshold of
  the current stage (iron condor weekly Rs 3 / Rs 3 / Rs 2), T-09's own comparison. No short at or below it ->
  refused naming the threshold. The expiry-day rule (ADR-216 "close any spread whose short is within 0.3%") names A-27
  through the same T-09 threshold, one value, not a second key.
  (5) A-35 "Time exit" closes every open leg (as A-31) and is offered on expiry day from the playbook guard time_exit
  (iron condor 14:30); before that time it is refused naming the time.
  Every one is priced by the one engine as a full After (ADR-008), with the refusals and warnings of REQ-155 AC-8.
  (6) Amendment 2026-11-03 (orchestrator, found live on paper strategy 82): A-24 and A-25 take PROFIT, so each is
  refused, with its reason, when the whole trade (booked plus open legs at the planned exit prices) is not in profit;
  a user is never shown "Take profit" beside a loss. Example: strategy 82 at -Rs 6,510 showed A-24 with the same
  figures as A-31 "Exit"; after this it reads refused "not in profit" and A-31 stays the exit.
