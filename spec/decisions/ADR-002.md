# ADR-002: Strategy-only execution and strategy modification

## Decision
- Model: Strategy → Legs → Entry Conditions → Risk → Adjustment Plan → Exit Plan → Execution Plan → Orders →
  Monitoring → Completion. Orders are execution artifacts belonging to a strategy.
- **Every executed trade belongs to a strategy.** No unrestricted individual orders, at every UX level.
  *You can change your strategy, but you cannot bypass the strategy.*
- A leg can never be treated as an unrelated standalone trade.
- Modification flow: Modify Strategy → proposed leg changes → recalculate max profit/loss, breakevens, current P&L,
  margin, charges, risk → Before/After comparison → prepare adjustment orders → user confirms → execute.
- Strategy versions are preserved (ADR-019).
