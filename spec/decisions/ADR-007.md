# ADR-007: Option Chain behaviour (Q43-Q57)

## Decision
| Q | Rule |
|---|---|
| Q43 | Same contract with opposite actions stays as separate legs. **No auto-netting.** |
| Q44 | Unavailable contract stays visible; valid alternatives may be suggested; user chooses explicitly; no silent substitution. |
| Q45 | Default columns: Strike, LTP, Change, IV, OI, Volume. Advanced: Bid/Ask, Delta, Gamma, Theta, Vega, OI Change, others. |
| Q46 | Hybrid live data: LTP/bid/ask stream; OI/IV at lower frequency. |
| Q47 | Persistent *Selected Legs* summary while scrolling; *Add to Strategy*. |
| Q48 | Duplicate contract: ask — increase quantity / keep separate / cancel. |
| Q49 | Validate before import: block serious errors; warn on legitimate cases (e.g. mixed expiries). |
| Q50 | Selections persist across expiry tabs; multi-expiry supported. |
| Q51 | Identify matching templates; never auto-convert or auto-execute. |
| Q52 | Unmatched combinations allowed as Custom Strategy. |
| Q53 | Explicit Buy/Sell per contract; **never infer the action**. |
| Q54 | +/- lot stepper using the broker-valid lot size; exact quantity in Advanced. |
| Q55 | Compact live preview: net premium, max profit/loss, breakevens, mini payoff. Full scenario table in Builder. |
| Q56 | Immediate remove + short Undo. |
| Q57 | Adjustment rules: global defaults + per-strategy overrides. |
| Q126 | Both exploration and construction; selected contracts are added to a strategy. |

Access: live/detailed chain is Pro-only and behind login (ADR-023, ADR-027).
