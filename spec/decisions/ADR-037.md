# ADR-037: Limited users can always exit an active strategy

## Decision
- **Q217 = A (owner, 2026-09-29).** Exit and closing orders for an already-active strategy are not "new trades". A
  Limited user can prepare and execute them (full or partial exit, all legs together).
- **Still Pro:** new entries, adjustments that add risk, new strategies, new simulations, the live Option Chain.
- **Why.** Same safety reasoning as Q89 = A (monitoring and alerts continue after expiry): a lapsed subscription must
  never stop a user getting out of risk. Blocking exits would push the user to close legs in Kite, which our app would
  then see as unexpected positions and a reconciliation mismatch that blocks execution (ADR-018).
- Written into ADR-023 and REQ-018 (AC-5 exception, AC-11).
