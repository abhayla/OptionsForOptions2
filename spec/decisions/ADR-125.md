# ADR-125: "Use Zerodha's number" clears an unreadable earlier-day plan

Why: Kite's order history covers the current day only, so the day after, "nothing placed" and "bought and sold back by
hand" look the same. The owner chose a confirmed, audited action that takes Zerodha's number without trading.
