# ADR-027: Navigation, home dashboard and public site

## Decision
- Q58: all real-time/detailed market data behind login. Q59: public site = product explanation, sample/static
  screenshots, clearly labelled sample/historical payoffs, pricing, FAQ, signup/login. No live data on public pages.
- **Home (Q81, §57) — PROPOSED, not confirmed.** Every handoff calls this the *proposed* home; the Latest handoff
  says "treat Q81 as the next decision to confirm if still unresolved", and no answer is recorded anywhere. Built
  to this layout unless the owner changes it (`spec/open-questions.md` Q81): Welcome [Name] · Create a Strategy · Explore Option Chain · Learn · 7-day Pro trial status ·
  *I already know my strategy* · Active strategies · Important alerts · Account status. Small live market strip
  allowed (§4). Connect Zerodha only in context.
- **Navigation (Q78)**:
  1. Home — Overview, Important alerts, Active strategies, Account status
  2. Strategies — My Strategies, Create Strategy, Strategy Builder, Live Strategies, Adjustments, Completed
  3. Positions — Current, Strategy-linked, Adjustment opportunities, P&L/risk
  4. Market — Option Chain, Underlying/index view, Market context
  5. Orders — Pending, Executed, Failed/partial, Execution history
  6. Alerts — Active, History, Notification settings
  7. Learn — Strategy education, Options concepts, Platform guidance
  - Avatar → Account & Settings: Profile, Zerodha connection, Subscription & Billing, Free Eligibility, Referrals,
    Notifications, Security, Preferences.
