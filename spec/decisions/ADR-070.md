# ADR-070: Public repository, up-to-date merges on main

## Why
- Issue #154: three pull requests on 2026-10-08 passed alone and failed together. GitHub's "require branches to be
  up to date" setting stops that, but on 2026-10-09 the API refused it for this private repository on the free plan
  (HTTP 403, "Upgrade to GitHub Pro or make this repository public").
- The owner chose making the repository public over paying for GitHub Pro or a project hook that only guards merges
  made through Claude.

## Alternatives not taken
- A project hook and wrapper around the merge tool (free, but does not stop a merge clicked on github.com).
- GitHub Pro (about 4 USD a month, keeps the repository private).
