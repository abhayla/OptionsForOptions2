# ADR-069: Settings values are identifiers or numbers

## Why
- ADR-064 closed the NAMES of risk limits and preferences; it did not say what their values may be. W-061, brought
  onto main, could not return a free-text value under the closed response rule, so it narrowed the values; the owner
  accepted that narrowing on 2026-10-09.
- Real values seen so far are numbers and short words (`max_loss` 8175, 9000); none is a sentence.

## Alternatives not taken
- Free-text values stored and shown back as user words built at the request boundary: needs the #148 design first.
