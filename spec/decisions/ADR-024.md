# ADR-024: Direct Zerodha customers: free Pro forever, verification and admin list

## Owner answers
- Owner (T1 #183): the owner is an authorised Zerodha partner; free for customers who opened with the owner.
- **Q61** (owner, T1 #191): a qualifying direct customer gets **full Pro, all features, free indefinitely**.
  Users without Zerodha who open through the owner's referral link become direct customers too (T1 #192).
- **Q62** (owner, T1 #193): their Billing page — *"You're already on Pro 🎉 … because you are a qualifying Zerodha
  customer"*; Plan Pro, ₹0, Complimentary/Active, renewal not applicable, **payment buttons disabled**, no upgrade
  prompt, no payment method. Internal: Plan = Pro, Price = 0, Source = Direct Zerodha Customer, Expiry = none.
- **Q69** (owner, T1 #207, #209): the owner provides a list of customers' Zerodha Client IDs; the user proves ownership
  by logging in through **Zerodha's official login** (never by typing an ID); match → free Pro. Keep an audit record
  (user, Client ID, method, time, result, approver, entitlement). Don't expose Client IDs unnecessarily.
- **Q70 = A**: Admin *Zerodha Customer Eligibility* screen — CSV bulk upload, manual add/edit/deactivate, search,
  linked user, verification date, entitlement status, periodic re-import, import history, audit, export, exceptions;
  duplicates/malformed IDs validated before applying.
