# ADR-093: Coding standards are automatic checks, sized to what they protect

## Why
- On 2026-10-16 a Kite host typed in a second module let a client bypass the order guard, and the IST offset was found
  defined in 11 modules: values with no single home drift.
- Rules kept only in prose were skipped repeatedly; checks that run by themselves are what hold.
- Every check costs CI minutes and agent tokens; checks that catch no real defect here are ceremony.
