# ADR-086: Contract names, IST times and four-part errors on the Builder screen

## Why
- A user cannot check a leg named "NSE_FO:47171" or read an ISO time; the 4a gate screenshots must show what a user
  would really see.
- REQ-065 AC-2 already requires every user-facing error to state what happened, the impact, what is blocked and the
  next action; the compact error forms broke that (impact missing, "This request." read as a broken sentence).
