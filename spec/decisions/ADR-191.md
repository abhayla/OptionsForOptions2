# ADR-191: record tests on records-only PRs; draft-PR CI before review for migration, reply and socket changes

Two owner answers from the kit 1.15.0 RCA. The record-test list closes the hole that turned main red on 2026-10-26. The
draft-PR step moves the database and Playwright reds that broke tests in other files from after review to before it,
without running 17-81 database test files on the production host.
