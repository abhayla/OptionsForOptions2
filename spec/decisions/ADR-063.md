# ADR-063: The engine owns the dividend yield

## Why
- The W-060 review measured the error on live inputs (2026-10-08 09:20): SENSEX 08-Oct 72,400 CE at vol 0.15,
  T = 0.000704 - Hull theta -111.07 per day, code -229.44; NIFTY 13-Oct 22,550 CE at vol 0.12 - Hull -11.89, code
  -14.17. Delta, gamma, vega and the forward itself were correct.
- ADR-061 listed the delta and gamma corrections and left theta out; scaling Greeks outside the engine invites the
  same miss for every Greek added later. Putting q in the engine makes every Greek right by construction.

## Example
NIFTY 13-Oct, S = 22,533.25, q = 0.0776, T = 0.0144, r = 0.065: the engine is called with S and q; it returns delta,
gamma, theta and vega already relative to spot. No caller multiplies by e^(-qT).
