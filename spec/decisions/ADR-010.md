# ADR-010: Live monitoring, statuses and the strategy control center

## Decision
- Monitored: P&L, underlying, distance from breakevens, distance from short strikes, DTE, IV, Greeks, margin
  utilization, entry/adjustment/exit conditions, market-data health (Q143).
- Statuses: 🟢 Healthy · 🟡 Watch · 🟠 Adjustment opportunity · 🔴 Exit condition reached (Q144).
- Rule-based, not predictive (§29).
- A position is a strategy/risk object, not a broker row (§30).
- **Strategy screen = control center**: definition, live state, entry/adjustment/exit rules, alerts, proposed
  adjustments, execution/reconciliation state, activity timeline (Q145).
- Position screen shows broker-linked positions; Strategy stays the controlling object (Q146).
