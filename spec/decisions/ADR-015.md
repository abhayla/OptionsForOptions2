# ADR-015: Market-data availability, stale data and per-strategy monitoring status

## ChatGPT (delegated, T2 #124)
- **Q182**: on disconnect: *"⚠️ Live market data disconnected. Last updated: 10:42:17 AM. Live strategy monitoring is
  paused."* The strategy stays; the user can view it and reconnect; current P&L/Greeks/risk are not shown as current;
  a trigger that may have happened during the gap is not claimed.
- **Q184**: per-strategy status — e.g. NIFTY strategy 🟢 monitoring, SENSEX strategy 🔴 paused, a draft unaffected.
- Each quote carries a health state (available · stale · delayed · unhealthy · unavailable) and every trigger record
  stores it (ADR-019).
