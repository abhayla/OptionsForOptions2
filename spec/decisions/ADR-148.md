# ADR-148: Structural second pass for a trimmed instrument list

Why: on 2026-10-19 Kite's list dropped 2,179 of 4,064 NIFTY contracts, all far strikes, and the ADR-058 count guard
refused every update until a forced one; every Execute was refused meanwhile. A trim cuts the tails of a strike ladder;
a broken download leaves holes, loses the near band, or loses a whole segment.

Spot source: the Kite list carries last_price 0 on every row, the index and futures rows included (measured on the
2026-10-21 08:40 file), and the catalogue keeps no index level. A stored-ladder midpoint was tried first and is wrong:
on the real lists the 2026-11-03 midpoint is 22625 against a NIFTY near 23119, so near-money strikes counted as far
and a list missing them was accepted. The anchor is therefore the exchange's own figure: the near-month NIFTY
future's base price in NSE's daily F&O contract file (the previous settlement), independent of the Kite list being
judged.

Freshness: 3 weekdays. On Monday 2026-10-19 the 19102026 file returned 404 and Friday's 16102026 file was the newest;
3 weekdays allows a late file across a weekend. Weekdays, not trading days (the repo has no holiday calendar), so a
holiday makes the limit stricter, never looser.

A wrong anchor can wrongly ACCEPT, not only wrongly refuse: if the index moves more than the band's margin after the
file's settlement (more than roughly 5% within 3 weekdays), strikes that are near the money today can sit outside the
band and be dropped. The base price is a futures settlement, a little above spot (23119.20 vs a spot near 23100 on
the real day). That residual risk is accepted with the 5% band; force=True remains the escape for a wrong refusal.

Held contracts: every order belongs to a strategy (ADR-002), so a saved strategy's legs cover every open position; no
positions table exists to read separately. The held set is read only after the count guards refuse.

Not done here: a cross-check against NSE's own contract file (deferred).
