# W-065: Live strategy numbers over the platform WebSocket

- **Core / Proof:** see frontmatter. The core proof is the first step and runs on live Kite data; the CI replay is
  not the core proof.
- **Spec basis:** REQ-035 AC-4 ('Entry Price, LTP, Entry Value, Current Value, Unrealized P&L and P&L % update live');
  REQ-048 AC-1 (vendor to gateway to engines to platform WebSocket to browser), AC-4 (one shared stream, no vendor
  subscription per user), AC-5 (browsers never connect to a vendor); ADR-068 (2) (push at most once a second per
  strategy, only when an input changed; REST fallback labelled not live), (1) (planned entry does not move with the
  live price); ADR-008 (no P&L maths in the browser); REQ-049 AC-5 and ADR-020 Q185 (not-live labels).
- **Not in this item:** margin (the margin item), the leg picker and Save Draft button.
- **Copy from:** legacy-reuse map rows 57 (`app/websocket/manager.py`, REFERENCE - connection manager pattern) and
  142 (`src/composables/autopilot/useWebSocket.js`, ADAPT - token off the query string, decoupled from autopilot);
  the server side builds on W-059's fan-out, not on algochanakya's ticker.
