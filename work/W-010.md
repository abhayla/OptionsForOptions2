# W-010: Admin qualifying Client ID list: CSV import, validation, audit, export

Domain service for the admin-maintained list of qualifying Zerodha Client IDs: CSV bulk import that reports duplicate and malformed rows and refuses to apply until they are resolved, manual add/edit/remove, search/filter, per-ID verification/association/entitlement status, import history, append-only audit trail, and export.

- **Core:** Importing a CSV with valid, duplicate and malformed rows applies nothing until the problems are resolved, then applies exactly the valid rows once.
- **Proof:** tests/admin/test_qualifying_import.py imports a 10-row CSV (7 valid, 2 duplicate, 1 malformed Client ID) and asserts: dry-run report lists the 3 problems, apply refused; after fixing, apply adds 7, a re-import of the same file adds 0; audit has one entry per change.
- **Spec basis:** REQ-020 and the decisions it cites; approved 2026-09-29 under ADR-045.
