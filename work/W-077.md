# W-077: "Checked at", names with no provider, strict time parsing (#245, #249, #244, #213)

- **Core / Proof:** see frontmatter.
- **Spec basis:** REQ-039 AC-3 ("Every important non-normal state shows what happened, when, what is blocked and the
  next action"); ADR-088 (owner, 2026-10-16: "Checked at" with the server's answer time; not connected = last
  connection attempt); ADR-086 (contract names, IST time format).
- **Decision by role (architect, owner delegation 2026-10-02):** the outcome route may read the catalogue store when no
  provider exists (#249) - ADR-086 item 1 requires a name, the catalogue (ADR-057) is the identity source, and no new
  external source is added.
- **What each state's time is (as built, ADR-088 clarified 2026-10-16):** computed / refused / not connected = the
  server's `answered_at` (with a provider, the provider context's clock, so a push and a REST answer of one snapshot
  match); not connected uses the answer time because the server keeps no record of connection attempts; unpriced =
  the newest planned-entry answer's `answered_at`; error = the server's HTTP `Date` header, and `Checked at Time not
  available` when the reply carries none (a dropped connection) - never the browser clock.
- **Not in this item:** which numbers count as live (W-065 rules stand); stale state wording (keeps "stale since").
