# W-014: Pre-execution safety checks and validation (pure, fail-closed)

A pure validation function over a strategy and an execution context (market open, broker connected, session valid, data health, margin estimate, reconciliation state, contract catalogue/eligibility — all inputs, no Zerodha call) that returns every failed check with a user-facing reason and never changes the strategy; unavailable contracts are reported, never silently substituted.

- **Core:** With every context check true the golden Iron Condor passes; flipping any single check blocks execution with that check's reason, and the strategy object is unchanged.
- **Proof:** tests/execution/test_safety_checks.py loops over every check in REQ-059 AC-1, flipping one at a time (mutation style), asserting blocked + reason + unchanged strategy; unavailable contract from the W-006 catalogue is reported, not replaced.
- **Spec basis:** REQ-059 and the decisions it cites; approved 2026-09-29 under ADR-045.
