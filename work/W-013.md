# W-013: Rule engine: one model for entry, adjustment and exit rules

One rule model (conditions over named inputs with AND/OR, V1 complexity limits) used for entry, adjustment and exit rules; V1 entry and exit condition types; exit action is the rule's choice (alert only, or alert + prepare exit orders); evaluation against a data snapshot returns triggered/not with the values that triggered it; optional plans; global defaults with per-strategy overrides.

- **Core:** An exit rule 'max loss 5,000' on the golden Iron Condor triggers at a snapshot where the engine's live P&L is -5,000 or worse and not above it, and reports the triggering value.
- **Proof:** tests/rules/test_engine.py evaluates exit/entry rules against snapshots built with the W-001 engine (live P&L from real formulas) including a boundary exactly at the threshold.
- **Spec basis:** REQ-041 and the decisions it cites; approved 2026-09-29 under ADR-045.
