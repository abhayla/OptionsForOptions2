# W-063: Outcome API

- **Core / Proof:** see frontmatter.
- **Spec basis:** REQ-034 AC-1 (every user sees the outcome view before execution: P&L, max profit/loss, breakevens,
  payoff, scenario behaviour, margin and risk - margin is returned as an explicit "not available yet" state until the
  margin item lands), AC-8 (payoff graph and scenario table from the same engine); REQ-033 (formulas, Verified);
  REQ-035 (table, done in W-004/W-034); ADR-008 (one engine, Decimal); ADR-061 (forward for IV/Greeks/Estimated Now);
  ADR-068 (planned entry; UX level per request, Standard default; not-live labels per ADR-020/REQ-049 AC-5/Q92);
  ADR-043 (FastAPI).
- **Not in this item:** the live push to the browser (WebSocket, Tier A, needs W-058), margin from Zerodha, saved
  strategies by id (needs W-061), the screen.
- **Copy from:** none - algochanakya's `routes/strategy.py` and `schemas/strategies.py` are REFERENCE/SKIP in the
  legacy-reuse map (they compute P&L in floats); the engine and table are this project's own.
