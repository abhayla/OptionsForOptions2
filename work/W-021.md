# W-021: Reconciliation with Zerodha positions (pure comparison and resolution)

A pure reconciliation function comparing Zerodha's net quantity per contract (an input) with each strategy's active version plus recorded standalone quantities: detects missing platform position, unexpected broker position, quantity/strike/side/expiry mismatch, external modification and partial execution; each mismatch recorded with time, broker state, platform state, difference and next action; manual resolutions explicit and audited (adopt broker position, prepare a closing order, mark as requiring attention, and 'broker flat → strategy exited' which closes deferred issue #19); a mismatch blocks new execution and adjustment execution for its own strategy only; a reconciliation trigger policy listing the events that must run it.

- **Core:** A broker net position that differs from the strategy's active version on one contract is reported as exactly that mismatch and blocks only that strategy, while a recorded standalone quantity on the same contract is not a mismatch.
- **Proof:** tests/reconciliation/test_compare.py builds the golden Iron Condor as the active version, a broker net-position map with a standalone 25 units on the sold CE and one wrong quantity on the put wing, and asserts exactly one mismatch, on the right strategy, with the recorded difference.
- **Spec basis:** REQ-060 and the decisions it cites; approved 2026-09-29 under ADR-045.
