# W-062: One-minute history from the live feed, final from Kite's candles

- **Core / Proof:** see frontmatter. The orchestrator's throwaway proof
  (`docs/research/kite-proof-2026-10-07/history_bars_proof.py`, F-34) ran the same comparison on the full recordings.

  creation, Option Chain, execution or monitoring); ADR-066 (Kite candles internal use only); ADR-067 (live first,
  final from Kite's candles, gaps backfilled, source on every bar); F-34.

  No user screen (REQ-051 AC-1, ADR-066).
