# W-068: Leg picker

- **Core / Proof:** see frontmatter (core proven before the build).
- **Spec basis:** REQ-035 AC-8 ("The Builder adds and edits legs from a picker that offers only listed, not-expired
  contracts of the chosen underlying (underlying, expiry, strike, CE/PE/FUT, buy/sell, lots)"); ADR-068 item 4
  ("offers only listed, not-expired contracts; Zerodha's own eligibility check comes with orders in 4b") and item 1
  (planned entry = LTP captured when the leg is added, or the mid of bid and ask when no LTP exists); ADR-020 Q185/Q186
  (without Zerodha: choose underlying/strategy, edit legs, set rules, save; no live prices; "the draft recalculates
  once connected"); REQ-053 AC-2 (catalogue stored separately from eligibility) and the ADR-058/059 update guards
  (kept: the load command calls apply_update unchanged); ADR-008 (the browser computes no P&L); ADR-003 Q226 (every
  user-facing message from the template catalogue); ADR-012 (the browser never talks to Zerodha).
- **Spec reading (no new rule):** a leg added while no live price exists has no planned entry; it gets one the first
  time a live price is available, which is ADR-020's "the draft recalculates once connected" applied to ADR-068
  item 1's capture.
- **Finding (2026-10-10, measured):** outside tests nothing loads the catalogue - `ofo_test` held 0 live contracts,
  and no job calls apply_update with Zerodha's list. The load command here is the manual step; scheduling it daily
  plus intraday (F-33 `daily-load-misses-intraday-additions`) is host/deploy work, not in this item.
- **Not in this item:** Zerodha's per-user eligibility check (4b, REQ-053 AC-3); suggestions and strike modes
  (REQ-027); live-price capture over the W-065 websocket (the capture here reads the same market snapshot the outcome
  route reads); scheduling the load.
- **Copy from:** legacy-reuse rows `src/views/StrategyBuilderView.vue` (2094) / `stores/strategy.js` (969) - ADAPT
  (P4): take only the leg-row add/edit form shape; drop its client P&L (`stores/strategy.js:722-743`), price
  fallbacks (`:359-374`) and basket call (`:622`). Expiry/strike lists come from our catalogue (row 10: the catalogue
  is the only source of lot size and strike gap), never from algochanakya's option-chain code.
