# W-124: Option Chain remainder (builder scope lane A, cluster A3)

- **Spec basis:** REQ-087 AC-1..AC-5; REQ-029 AC-3, AC-5, AC-9; REQ-030 AC-14, AC-16; REQ-031 AC-1..AC-3; ADR-008, ADR-048,
  ADR-152, ADR-165 (8). Brief: docs/process/builder-scope-briefs/A3-option-chain-remainder.md.
- **One requirement linked** (tests/test_spec_integrity.py: a work item links exactly one); the other requirements' ACs
  built here are named in the PR body: REQ-029 AC-3/AC-5/AC-9, REQ-030 AC-14, REQ-031 AC-1..AC-3.
- **Server:** `ofo/engine/chain_values.py` (the maths), `ofo_app/chain_push.py` (cell fields), `ofo_app/chain_preview.py` +
  `POST /api/market/chain/preview` (the outcome route's own numbers, no margin), migration `0022_user_settings` +
  `ofo_app/user_setting_store.py` + `GET/PUT /api/user-settings/chain-strikes`. `MAX_STRIKES_EACH_SIDE` 15 -> 40 and the
  default 15 -> 10 (REQ-087 AC-3).
- **Frontend:** `lib/chainDisplay.js`, `composables/useChainPreview.js`, `pages/OptionChainPage.vue`, a "Select from
  Option Chain" link in `StrategyBuilderPage.vue`.
- **Not built here:** REQ-030 AC-3 / AC-7 exact quantity at Advanced, AC-12 (the already-in-strategy prompt) and AC-13
  (import-time validation list beyond the existing permission check), REQ-029 AC-10 (the Builder's expiry rule), REQ-029
  AC-7 (launch scope). Greeks use the engine's forward model; a chain whose forward cannot be derived shows dashes.
