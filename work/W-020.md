# W-020: Strategy activity timeline and rule-trigger records

An append-only chronological timeline per strategy (every AC-1 entry type) that cannot be edited or deleted; rule-trigger records holding the rule, exact input values, threshold, timestamp, data source, data health and active version; follow-up records (alert, order prepared, confirmation, executed, broker report, reconciliation result); and a 'Why did this trigger?' answer built only from those records. Reuse the merged audit log's append-only and hash-chain design (backend/ofo/audit) rather than a second mechanism where it fits.

- **Core:** A max-loss rule trigger on the golden Iron Condor produces a record whose 'Why did this trigger?' answer quotes the rule, the exact live P&L, the threshold, the data health and the version — nothing invented.
- **Proof:** tests/timeline/test_why.py evaluates a W-013 rule against a snapshot built with the engine, records the trigger, and asserts the answer text contains exactly the recorded values.
- **Spec basis:** REQ-040 and the decisions it cites; approved 2026-09-29 under ADR-045.
