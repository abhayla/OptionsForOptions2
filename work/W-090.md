# W-090: Range customisation and the At Expiry / Estimated Now switch (REQ-034 AC-4, AC-6)

- **Spec basis:** REQ-034 AC-4 ("Step and range are configuration, not code constants; ... the user can customise it",
  Q33B = E: the user customises the RANGE), ADR-042 (the column step is an Admin setting per index), AC-5 (grid anchored
  to rounded 100-point levels), AC-6 (At Expiry default and exact, Estimated
  Now model-based and labelled, Q33A = C), AC-2 and AC-5 (live level and breakevens always inserted).
- **Found by:** GC-1 4a audit: the backend switch exists, the frontend has none; the range is not user-settable.
- **Open, not decided here:** whether margin shows on the outcome view (REQ-034 AC-1 says "margin and risk"; the audit
  found a fixed NOT_AVAILABLE_YET). That is decided with ADR-099's margin work in GC-2a, not in this item.
