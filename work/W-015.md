# W-015: Append-only audit log and event catalogue

An append-only audit log (no update, no delete API; tamper evidence via a hash chain) with the full event-type catalogue from REQ-064 AC-1 including ADR-029 identity events, structured payloads, actor, time and correlation id.

- **Core:** Appending events builds a hash chain; any modification or removal of a stored event is detected by verification.
- **Proof:** tests/audit/test_log.py appends one event of every catalogued type, verifies the chain, then mutates, deletes and reorders an event in the stored list and asserts verification fails each time.
- **Spec basis:** REQ-064 and the decisions it cites; approved 2026-09-29 under ADR-045.
