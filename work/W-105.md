# W-105: basket return on the shared redirect URL

- **Spec basis:** REQ-073 AC-3 ("When the user returns from Kite, the platform reads the actual order states and
  positions from Zerodha and reconciles them"); ADR-097 (2) ("no app code or assistant action sends an order"): the
  landing only redirects; the page (W-104) reads back.
- The redirect carries none of the incoming query (the request_token never reaches the address bar); the access-log
  filter still drops the query of the basket-return hit.
