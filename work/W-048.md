# W-048: Strategy preferences: an unranked set of template ids

A user can mark several strategy templates as preferred, all with equal priority (an unranked set), add and remove them, and an unknown template id is refused. Backend only; the Onboarding and Settings screens are out of scope (no UI yet).

- **Core:** A user can mark several strategy templates as preferred, all with equal priority (a set, no ranking), add and remove them, and an unknown template id is refused.
- **Proof:** tests/strategy/test_preferences.py using real template ids from backend/ofo/strategy/catalogue.yaml; red first (module absent), green after.
- **Spec basis:** REQ-068 AC-1: "Users can mark several preferred strategy types, all with equal priority, at onboarding and later in Settings → Strategy Preferences (Q114, Q115)." REQ-025 AC-4: "A preferred strategy is never silently forced or auto-selected."
