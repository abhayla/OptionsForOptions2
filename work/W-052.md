# W-052: PostgreSQL audit store

- **Core:** stored events reload and re-verify; tampering is detected.
- **Spec basis:** REQ-064 AC-2 ("Audit and timeline records are append-only."); REQ-063 AC-5 (per-event-type field
  allowlist for audit payloads; broker-payload event types stay out until W-017); ADR-023 Q256 / W-051 clock.
- **Copy from:** none - algochanakya has no hash-chained audit log (legacy-reuse.md M9); the store follows
  `backend/ofo/audit/` (`models.py` canonical JSON with `$decimal`/`$datetime` tags, `log.py` HeadAnchor).
- Payload stored as JSONB in its canonical tagged form so hashes recompute byte-for-byte; appends take
  `pg_advisory_xact_lock`; the anchor (count, last hash) is a separate table the application role can only update
  through the append function.
