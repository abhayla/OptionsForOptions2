# W-011: Complimentary Pro for qualifying Zerodha customers: match, grant, audit

Given a Client ID verified by the Zerodha login (an input here; no Zerodha call), match it against the qualifying list and grant open-ended Direct Zerodha Customer Pro through the entitlement engine; on no match return the three alternatives; audit every check without exposing the Client ID unnecessarily.

- **Core:** A verified Client ID on the list yields an open-ended Direct Zerodha Customer entitlement event and an audit record; one not on the list yields no entitlement and the three alternatives.
- **Proof:** tests/entitlements/test_complimentary.py with the W-010 list and the W-007 engine: access_at is PRO with source DIRECT_ZERODHA_CUSTOMER and no end; a non-listed ID stays on its trial/Limited and gets the alternatives list.
- **Spec basis:** REQ-019 and the decisions it cites; approved 2026-09-29 under ADR-045.
