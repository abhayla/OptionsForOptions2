# W-005: Generic strategy model and templates as data

Represent any combination of the six leg types, any number of legs and multiple expiries; named strategies as data templates (adapted from algochanakya seed_strategies.py with provenance, reworded per ADR-003) resolved against a spot level and strike gap; any non-matching combination is a valid Custom Strategy.

- **Core:** The Iron Condor template, resolved at NIFTY spot 23,200 with strike gap 50, yields four legs the engine prices, and a template added as data needs no code change.
- **Proof:** tests/strategy/test_templates.py loads every template from the data file, resolves each at real NIFTY/SENSEX strike gaps (50/100, measured 2026-09-29), and runs each through the engine.
- **Spec basis:** REQ-028 and the decisions it cites; approved 2026-09-29 under ADR-045.

## Parameter defaults (round 3, 2026-09-29): defaults (ADR-045), not settled

Templates are parametric shapes (ADR-006 Q8): each leg strike is a linear expression of named step counts from
the ATM strike, and matching solves the strikes back for those parameters (`backend/ofo/strategy/`). The spec
sets no widths, distances or ranges, so every value below is an overnight default under ADR-045 for the owner to
confirm or change, not a decision:

- defaults are the legacy algochanakya offsets (0, +/-2, +/-4 steps at NIFTY gap 50);
- bounds: signed strike parameters -20..+20 steps, widths 1..20 steps; hard cap 50 steps anywhere;
- moneyness carried by a template (sign constraints or a fixed ATM strike): Straddle (both) and Iron Fly short
  strikes at ATM; Strangle (both), Cash-Secured Put, Covered Call's short call and Jade Lizard's short strikes
  out of the money. Every other template may sit anywhere on the strike ladder (a shifted Iron Condor is still an
  Iron Condor);
- ATM is spot rounded to the strike gap, a tie rounding up (ADR-045 default).
