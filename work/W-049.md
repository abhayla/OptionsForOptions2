# W-049: Adjustment metric calculators for the reference-video values

Calculators for the `pass` rows of the reference-video table, registered in the W-045 registry. Every P&L, payoff
and model number is computed by the one engine (ADR-008); each value records its inputs (REQ-047 AC-5).

- **Core:** Calculators registered in the W-045 registry compute the reference-video values for a real strategy from the ONE engine (golden Iron Condor with one leg closed: rows 10, 28, 4, 26).
- **Proof:** tests/adjustment/test_metrics.py on the golden fixture and the real instrument catalogue; expected values hand-computed; red first, green after.
- **Spec basis:** REQ-071 AC-1; spec/technical-design/adjustment-data-contract.md rows 4-11, 14, 16-18, 26-29 and "Owner readings of the unclear values (2026-09-29, Q246)" (rows 10, 26, 28) + the Q248 note (rows 4, 26); scenario-calculations.md section 4; REQ-047 AC-5; ADR-008.
- **Not built:** rows 12 and 13 (feasibility `unclear`), 19-25 and 30 (`unknown`/`fail`/out of V1). Rows 1, 2, 3, 15 are raw feed/broker values with no calculation.
