# W-041: Strategy state machine: approved transitions only

A strategy's operational state (the 12 states of REQ-039 AC-1) changes only through the owner-approved transition
table in spec/data/domain-model.md §6 (Q240); every change is a recorded, audited transition whose guard reads the
strategy record itself, and every non-normal state explains what happened, when, what is blocked and the next action.

- **Core:** a strategy's operational state changes only through the owner-approved transition table; e.g.
  Reconciliation Required -> Active is refused unless a recorded manual resolution exists, and Active -> Monitoring
  Paused happens only on a user pause.
- **Proof:** a table-driven test tries EVERY (from, to) pair of the 12 states and asserts exactly the approved ones
  are allowed (with their trigger), every other pair refused; red first, green after.
- **Spec basis:** REQ-039 AC-1..AC-3; spec/data/domain-model.md §6 (owner-approved Q240, 2026-09-29); Q222
  (manual-only unblock); REQ-043 AC-4 (monitoring status is separate from this state machine); ADR-019.
