# W-033: Performance tests count work, not wall-clock time

Finding wall-clock-assertion-flakes-under-load: a threshold like `perf_counter() - start < 1.0` measures machine load, not the code's cost, so it failed three times on 2026-09-29 under parallel agents and passed on re-run. Each such test asserts a deterministic work count instead (`tests/work_count.py`), and `tests/test_no_wall_clock_asserts.py` stops the pattern coming back.

- **Core:** tests/strategy/test_versions.py::test_one_thousand_history_appends_stay_fast asserts the COUNT of per-append validation work (linear in appends) instead of wall-clock time, and still fails if append re-validates the whole history each time.
- **Proof:** a scratch mutant that makes append re-validate the whole history turns the rewritten test red; the real code is green; the test passes under parallel CPU load.
- **Spec basis:** spec/testing/core-invariants.md states no performance or test-determinism rule (searched: time, fast, performance, determin); the finding file knowledge/findings/wall-clock-assertion-flakes-under-load.json; the builder-brief input-domain checklist ("one-by-one append of 1,000 items must stay fast"). No product behaviour change.
- **Scope note:** a work item links exactly one requirement (tests/test_spec_integrity.py), so REQ-038 (the core test's requirement) is the link. The other four rewritten tests stay under their own requirements and are named here only: tests/execution/test_plan.py (REQ-056 AC-2), tests/reconciliation/test_compare.py (REQ-060 AC-2), tests/strategy/test_builder_history.py (REQ-070 AC-2), tests/timeline/test_timeline.py (REQ-040 AC-1).
- **Guard (card correction, class 1, after verification):** `tests/test_no_wall_clock_asserts.py` is a cross-cutting
  detection check for the finding, not an acceptance test of REQ-038 (whose AC-2 is about history vs versions), so it
  is not listed in `tests_required`. Known gaps (verifier): `timeit`, `datetime.now()` differences, `import time as t`
  and thresholds held in a named constant are not flagged.
