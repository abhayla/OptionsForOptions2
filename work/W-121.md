# W-121: order path switched off (builder scope Step 1)

- **Spec basis:** ADR-165 (1) "Placing orders at Zerodha or any other broker is out of this scope"; REQ-073 AC-6.
- **Switch:** `backend/ofo_app/order_path_switch.py` (`order_path_on`, `require_order_path`); on only for `APP_ENV` exactly
  `test` and `OFO_ORDER_PATH` in 1/true/yes/on.
- **Not here:** the stop-loss module switch (REQ-073 AC-4 is a different, unbuilt switch); read routes stay open.
