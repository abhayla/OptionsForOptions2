# W-037: Reconciliation compare is linear in active strategies

Addresses #64.

- **Core:** reconciliation compare's work grows linearly in active strategies: with all strategies mismatched and zero broker contracts, the call count at 200 strategies is at most 2.5x the count at 100 (3.5x before).
- **Proof:** tests/reconciliation/test_compare.py restores the strategies-scaling check using tests/work_count.py assert_linear; red on origin/main, green after; every existing compare test unchanged and green.
- **Spec basis:** REQ-060 AC-2 ("It detects: missing platform position, unexpected broker position, quantity/strike/side/expiry mismatch, external broker modification, and partially executed strategy") and AC-7; ADR-018; Q224 (a contract held by several strategies that disagrees with Zerodha blocks every holder) must behave identically. Tier A: reconciliation blocks execution.
