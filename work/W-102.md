# W-102: the full cost in the Execute reply

- **Spec basis:** REQ-056 AC-8 (the order plan carries margin and charges), ADR-097 (a final yes on the exact contract,
  side, quantity, limit price and cost), REQ-073 AC-1 (the Execute route it extends).
- **One requirement:** the brief named [REQ-056, REQ-073]; `trace_check.py` refuses a work item over two requirements
  that share AC ids (one evidence file cannot prove both), so this card carries REQ-056 only and the route test is
  listed under AC-8.
- **Margin shown:** `margin_required` is the gate's figure from `_zerodha_margin` (ADR-094 `required_total`). For a
  closing basket Zerodha's `final.total` is negative (real exit -214.5) and the gate's figure is 0.00 (ADR-094 / #321:
  a release is never a credit), so the exit reply shows "0.00", not "-214.50".
