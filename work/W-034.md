# W-034: Strategy table TOTAL row: risk-based P&L % and options-only Entry Value

Owner decision Q233 (2026-09-29): TOTAL P&L % = unrealized P&L / max loss (risk-based); "—" when max loss is UNLIMITED or zero. TOTAL Entry Value only for options-only strategies.

- **Core:** The golden condor table's TOTAL row shows P&L % +16.7% and Entry Value 19,800; a futures strategy shows "—" for TOTAL Entry Value.
- **Proof:** tests/table/test_total_row.py, exact Decimal values, red on origin/main, green after.
- **Spec basis:** REQ-035 AC-2; ADR-008 (max loss and unrealized P&L come from the engine); Q233.
