# W-043: Complete and Retry refusals return a reason

Addresses #71. Found by the W-036 verifier (2026-09-29).

- **Core:** Complete and Retry with a freeze below one lot return a "Nothing prepared: <reason>" result (like Close
  since W-036) instead of raising ValueError, with no state change.
- **Proof:** tests on the real catalogue fixture (NIFTY lot 65, SENSEX lot 20), red on origin/main, green after.
- **RCA:** `_prepare_missing` calls `sequence_plan` unguarded, so its slicing ValueError propagates to the caller.
- **Class:** slicing refusals in Complete and Retry (backend/ofo/execution/partial.py): before, raise; after, the
  flow's standard refusal result; Close unchanged.
- **Spec basis:** REQ-058 AC-6 "V1 never resubmits a failed order automatically; the failure is shown with its
  reason and the user chooses the next action (Q193)"; issue #71.
