# W-106: holdings read on the Kite read door

- **Spec basis:** ADR-097 ("/portfolio/holdings is read before and after and must be unchanged."); REQ-073 AC-4 ("No
  code path places an order through the order-placement API; a test fails if one is added.").
- Quantity policy: a JSON integer only. `10.5`, `10.0`, `"10"`, `true` and a missing value all refuse the read
  (fail closed); Kite documents integers.
- `GET /portfolio/holdings` is allow-listed for `ofo_app/kite_reads.py` only, and the door sends it with no query or
  fragment.
