# W-019: Order lifecycle states

An order model with exactly the states Prepared, Submitted, Pending, Partially Executed, Executed, Rejected, Cancelled and their allowed transitions (anything else refused); a submitted order changes no strategy state or position until a broker-confirmed execution event; strategy state is never derived only from order rows.

- **Core:** A submitted order leaves the strategy's positions unchanged until a broker fill confirmation arrives, and then only the confirmed quantity changes.
- **Proof:** tests/orders/test_lifecycle.py drives one order through every allowed transition and every disallowed one, and asserts positions change only on confirmed fills.
- **Spec basis:** REQ-057 and the decisions it cites; approved 2026-09-29 under ADR-045.
