# W-035: Client ID validation follows the owner's format

Owner decision Q234 (REQ-020): a Zerodha Client ID is 6 characters, 2 letters + 4 digits or 3 letters + 3 digits; letters are case-insensitive on input and stored upper-case. Replaces the unverified W-010 guess.

- **Core:** CLIENT_ID_PATTERN accepts exactly 6-character IDs of 2 letters + 4 digits or 3 letters + 3 digits (AB1234, ABC123) and refuses the old guess's extra shapes (AB123, AB12345, XYZ123456, ABCD12).
- **Proof:** tests/admin tests with those real-shape examples are red on origin/main and green after the change; the full suite stays green.
- **Spec basis:** REQ-020 "Owner decision (2026-09-29, Q234): Zerodha Client ID format".
