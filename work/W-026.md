# W-026: Strategy-only execution and Strategy Guard

Every order references a strategy and strategy version, and an order without one cannot be created (AC-1); no API path offers a standalone single-contract buy/sell (AC-2, backend part); the Option Chain and Builder can only prepare legs, and submission goes only through the strategy's execution flow and the pre-execution gate (AC-3); Strategy Guard: before execution or modification, an action that changes the strategy's risk profile (max loss, max profit, breakevens, unlimited side, margin) is detected by the engine and returns 'This action changes your strategy's risk profile' with the before/after consequences, and cannot proceed without an explicit acknowledgement (AC-5). AC-4 (screen message) is UI work.

- **Core:** Removing the bought 23,600 CE from the golden Iron Condor is detected by Strategy Guard as a risk-profile change (upside max loss goes from a number to UNLIMITED) and cannot proceed without acknowledgement, while changing only the quantity-neutral order type is not flagged.
- **Proof:** tests/execution/test_strategy_guard.py builds the golden condor and the modified versions with the engine and asserts the guard result and the before/after values.
- **Spec basis:** REQ-036 and the decisions it cites; approved 2026-09-29 under ADR-045 (fourth set).
