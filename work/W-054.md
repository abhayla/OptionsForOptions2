# W-054: Frontend skeleton and navigation

- **Core:** browser -> Vite proxy -> FastAPI -> PostgreSQL, visible on one page, in one Playwright run.
- **Spec basis:** REQ-009 AC-1..AC-8 (the seven sections with their sub-items and the account menu; AC-5: Orders lists
  "strategy-linked orders only, never an order-entry form"); ADR-049 (Tailwind 4, owner references, one cobalt accent,
  health colours reserved); ADR-012 (the browser never talks to a market-data vendor); ADR-046 (app-tests.yml).
- **Copy from:** `spec/technical-design/legacy-reuse.md` M7: `package.json`, `vite.config.js` (+ `/api`, `/ws` proxy),
  `eslint.config.js` (+ vendor-host ban), `main.js`, `index.html`, `src/router/index.js` (structure only, new route
  table), `src/services/api.js` (same-origin, httpOnly cookie, no localStorage token), `KiteLayout.vue` + `KiteHeader.vue`
  (renamed, restyled; broker switching removed), `useToast.js`, `useScrollIndicator.js`, `src/tests/setup.js` + helpers,
  `playwright.config.js` + page-object structure + `data-testid` convention. Not copied: `kite-theme.css`, any
  per-broker store/service, autopilot/ai/ofo code.
- Each section page is an empty placeholder naming its sub-items; no feature screen is built (ADR-030).
